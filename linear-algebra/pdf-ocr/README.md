# PDF 可检索文本归档

本目录参考 `computer-organization/pdf-ocr/` 的用途：保存 GitHub 可全文检索的学习文本，同时把原 PDF 保留在 ChatGPT Project 作为权威版本。

- `27张宇基础30讲线代.pdf`：当前版本 213 页，文本层不可用，精确内容按原页读取。

## 原则

GitHub 文本只负责检索和长期恢复。遇到矩阵、行列式、分式、上下标、正负号、转置、逆、伴随等数学符号时，以原 PDF 页面为准，不根据 OCR 猜测。
