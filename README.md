## 工作方式

1. 真题按“知识点定位 → 独立作答 → 逐步纠错 → 同类迁移 → 错题归档”推进。
2. 新题型详细讲，重复题型逐步提速。
3. 所有易错条件、公式、算法边界、复杂度结论持续沉淀到错题本。
4. 当前原始 PDF 保留在 ChatGPT 项目中；本仓库主要维护可持续更新的索引、刷题进度、错题与总结。
5. 基础资料现已基本齐全，下一阶段重点转向目标院校历年真题。
