# 408 真题

本分支专门维护 **计算机 408 统考真题**。

当前已经接入 2009—2023 年完整 408 真题 PDF。由于本项目当前目标是数据结构刷题，本分支先把每套 408 中属于 **数据结构** 的部分单独摘出并建立索引，其余组成原理、操作系统、计算机网络题暂不进入数据结构刷题队列。

## 数据结构摘取规则

- 单项选择题：2009—2023 年均摘取 **第 1～11 题**。
- 综合应用题：按题目实际内容判断是否属于数据结构，题号并非每年完全固定。
- 原始 PDF 继续保留在 ChatGPT 项目资料中；仓库中维护题号定位、题型标签、刷题进度和后续错题记录。
- 题面出现扫描模糊或文本识别异常时，刷题时回到原 PDF 页面核对，不根据转写猜题。
