## 来源保存原则

参考仓库中计算机网络、操作系统等分支的做法：

- 原始 PDF 继续保留在 ChatGPT 项目中作为权威来源。
- GitHub 分支长期保存 **文件清单、哈希、章节地图、可检索文本/OCR、学习笔记、题库与进度**。
- 精确公式、图示、题面、动画页最终以原 PDF 页为准。
- 不把其它 408 科目的资料或题目混入本分支。
