## 当前整理原则

1. 知识点文件只写 **年份-题号 + 题型 + 题干摘要/核心考点**，默认不写答案，便于真正刷题。
2. 需要做某一题时，再回到原始 408 真题读取完整题面、选项、公式、代码和图。
3. 图形、公式、代码或文字转写出现异常时，以原卷为准，不依据摘要猜题。
4. 年份索引用于整套刷题；知识点索引用于专项训练；JSONL 用于覆盖率和错题状态的自动统计。
