# 计算机网络考研学习分支

本分支用于计算机网络的资料归档、知识学习、真题刷题、错题复盘与进度追踪。

## 目标

- 以用户上传资料为主线，保持原资料章节、术语和题型组织。
- 面向考研/408计算机网络，最终进入按年份与知识点组织的真题刷题阶段。
- 所有题目保留来源、页码/题号、年份（如有）、知识点、作答结果和错误原因。
- 资料不清晰时回查原PDF页面，不凭空补题或改题。
- 先完成资料收集与知识体系整理，再统一做真题覆盖率审计。

## 目录

- `sources/INDEX.md`：当前资料清单与入库状态
- `sources/CHAPTER_MAP.md`：章节知识地图与后续学习顺序
- `CURRENT_STATE.md`：当前学习状态与下一步
- `PROGRESS.md`：章节、真题与错误点进度
- `notes/`：每日学习笔记
- `question-bank/`：结构化真题/练习题与刷题记录
