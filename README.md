## 数据结构摘取范围

- **2009 年单项选择题：第 1～10 题**。第 11 题已进入计算机组成原理。
- **2010—2023 年单项选择题：第 1～11 题**。
- 综合应用题按实际题目内容逐年判断，不机械固定题号。
- 原始 PDF 保留在 ChatGPT 项目资料中；GitHub 分支主要维护题目定位、考点摘要、刷题进度和错题记录。
- 题面、图形或公式出现识别异常时，以原 PDF 页面为准，不依据转写猜题。
