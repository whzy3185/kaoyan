# 每日笔记与视频学习笔记

## 每日学习笔记

每日学习结束后新增一份笔记，例如：

- `2026-09-20.md`
- `2026-09-21.md`

建议包含：今日进度、知识点、必须记忆结论、易错点、做题结果、待复测题和下一次起点。
