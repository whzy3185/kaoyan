状态：已学习

## 一、视频主线

本视频覆盖网络层后半部分及相关配套协议，整体顺序为：

DHCP → ARP → ICMP → NAT/NAPT → IP分组转发 → 子网/分片综合题 → RIP → OSPF → BGP → IP多播/IGMP → 移动IP → 路由器结构 → SDN/OpenFlow。

视频大量使用“画出通信路径、逐跳改地址、根据路由表逐项判断”的方法，后续教学应沿这个思路讲。

## 二、DHCP

视频强调 DHCP 用于主机动态获得 IP 配置，基于 UDP：

- DHCP 服务器端口：67
- DHCP 客户端端口：68

典型四阶段：

1. DHCP Discover
2. DHCP Offer
3. DHCP Request
4. DHCP ACK

客户端最开始还没有 IP，因此 Discover 的典型字段：

- 源 IP：`0.0.0.0`
- 目的 IP：`255.255.255.255`
- 目的 MAC：`FF-FF-FF-FF-FF-FF`

视频板书强调：没有 IP 地址时，必须依靠广播把请求送出去。

做题时区分两层广播：

- IP 层广播地址
- 以太网目的 MAC 广播地址

## 三、ARP

ARP 解决“已知目标 IP，怎样得到本局域网下一跳 MAC”的问题。

视频的判断顺序：

1. 先查 ARP 高速缓存。
2. 缓存有映射 → 直接使用。
3. 没有映射 → 在**本局域网广播 ARP 请求**。
4. 目标主机识别自己的 IP 后返回 **ARP 单播响应**。
5. 发送方把 IP→MAC 映射写入缓存。

ARP 请求的关键特点：

- 请求：广播。
- 响应：单播。

跨网络时不能“ARP 远端主机的 MAC”。  
主机应先确定目的主机是否与自己同网：

- 同网 → ARP 目的主机。
- 不同网 → ARP **默认网关/下一跳路由器接口**。

这是网络层综合题最重要的逐跳判断之一。

## 四、ICMP

视频把 ICMP 视为网络层配套协议，ICMP 报文封装在 IP 数据报的数据部分。

重点用途：

- 差错报告
- 网络诊断/询问

视频涉及的典型差错报告：

- 终点不可达
- 时间超过
- 参数问题
- 重定向

常见应用：

- PING
- traceroute

视频还强调“并非所有错误都继续回 ICMP 错误报文”，例如：

- 对 ICMP 差错报文本身不再发送 ICMP 差错报文。
- 对分片后的非首片通常不发 ICMP 差错报告。
- 对具有多播地址的数据报不发 ICMP 差错报告。
- 对某些特殊地址不发差错报告。

做题时先判断“该 IP 数据报是否属于允许产生 ICMP 差错报告的对象”。

## 五、NAT

NAT 用于专用网主机借助全球 IP 与互联网通信。

视频的核心路径：

### 专用网 → 互联网

NAT 路由器根据转换表：

- 把源私有 IP 改成自己的全球 IP。
- 目的互联网 IP 保持不变。

### 互联网 → 专用网

返回数据到 NAT 路由器后：

- 查 NAT 转换表。
- 把目的全球 IP 改回对应私有 IP。
- 再转入专用网。

视频特别强调 NAT 的限制：

- 普通 NAT 通信通常由专用网内部主机主动发起。
- 外部主机不能仅凭私有地址直接主动找到内部主机。
- 一个全球 IP 的纯地址映射能力有限。

## 六、NAPT / 端口号复用

为让多个内部主机共享少量甚至一个全球 IP，需要把**端口号**一起纳入映射。

视频中的 NAPT 表把：

`私有IP:私有端口`

映射为：

`全球IP:转换后的端口`

因此多台内部主机即使使用相同本地端口，也可通过 NAT 路由器使用不同外部端口区分会话。

做题时要逐项检查：

- 源 IP 是否改变
- 目的 IP 是否改变
- TCP/UDP 端口是否改变
- 回程时依据哪条表项恢复

## 七、IP分组转发

视频用拓扑反复训练以下判断链。

### 第一步：判断是否同网

对“目的 IP”和“本机子网掩码”按位 AND，得到目的网络地址；与本机网络前缀比较。

- 同一网络 → 直接交付。
- 不同网络 → 间接交付，交给默认网关。

### 第二步：确定下一跳

路由器按路由表逐项匹配目标前缀。

重点包括：

- 主机路由：`a.b.c.d/32`
- 默认路由：`0.0.0.0/0`
- 最长前缀匹配

### 第三步：解决下一跳 MAC

路由表确定下一跳 IP/输出接口以后，再通过 ARP 获得下一跳 MAC。

因此“路由选择”和“ARP”是两个连续步骤：

- 路由表决定**把包交给谁/从哪出**。
- ARP 决定**以太网帧写哪个目的 MAC**。

## 八、子网与分片综合题

视频中用 2015、2018、2022 等题型反复训练：

- 子网地址
- 广播地址
- 可分配主机数
- 默认网关
- 子网掩码
- MTU
- IPv4 分片

IPv4 分片关键：

- 每个分片都有自己的 IP 首部。
- 除最后一片外，数据长度通常要满足片偏移单位要求。
- 片偏移以 **8B** 为单位。
- `MF=1` 表示后面还有分片，最后一片 `MF=0`。

## 九、RIP

RIP 是距离向量型内部网关协议。

视频强调：

- 基于 UDP。
- 端口 520。
- 周期性向相邻路由器通告路由信息。
- 距离以跳数衡量。
- 最大有效距离 15，16 表示不可达。

更新路由表时重点看：

1. 来自哪个邻居。
2. 对方给出的距离先加 1。
3. 原路由下一跳是否就是该邻居。
4. 若不是同一下一跳，再比较新旧距离。

视频特别强调 RIP 的问题：

### 坏消息传得慢 / 计数到无穷

链路断开后，邻居可能把错误的“好消息”重新告诉故障侧路由器，形成环路，距离逐轮增加，直到 16。

所以看到“某网络突然不可达，但邻居仍保留旧路由”时，要警惕 RIP 的慢收敛。

## 十、OSPF

OSPF 是链路状态型内部网关协议。

视频强调：

- OSPF 报文直接封装在 IP 中，IP 协议号为 89。
- 支持 CIDR。
- 路由器通告的是**链路状态信息**。
- LSA 在区域内泛洪。
- 各路由器最终形成一致的链路状态数据库（LSDB）。
- 在完整拓扑基础上运行最短路径算法。

与 RIP 的核心对比：

- RIP：告诉邻居“我到各网络有多远”。
- OSPF：向区域传播“我的链路状态是什么”。

OSPF 支持分层区域设计，视频提到主干区域与区域间结构，用于扩大规模并控制链路状态信息传播范围。

## 十一、BGP

BGP 是自治系统之间的外部网关协议。

视频强调：

- 基于 TCP。
- 自治系统之间使用 eBGP。
- 同一 AS 内为传播外部路由可使用 iBGP。
- BGP 传播的是路径向量/AS 路径等属性，不只是“距离”。

路由选择中视频重点讲了：

1. 本地偏好 LOCAL-PREF
2. AS-PATH 长度
3. 当高优先级属性相同后，可使用“热土豆”思想，尽快离开本 AS

热土豆路由的本质：  
在外部路径条件相当时，选择本 AS 内代价更小、能更快到达出口的边界路由器。

## 十二、IP多播与 IGMP

视频后段进入 IP 多播：

- D 类多播地址映射到以太网多播 MAC。
- IP 多播地址到 MAC 多播地址不是一一映射，存在多对一映射。
- IGMP 用于主机与本地多播路由器之间的组成员关系管理。

做题时要区分：

- IP 多播地址
- 以太网多播 MAC
- 组成员管理协议 IGMP

## 十三、移动 IP

视频给出移动 IP 基本概念：

- 归属网络
- 永久地址（归属地址）
- 归属代理
- 外地网络
- 外地代理
- 转交地址

并展示“通信者 → 归属代理 → 外地网络/移动主机”的转发路径以及三角路由问题。

做题核心是：移动主机移动后仍保持永久地址，对外位置变化通过代理和转交地址机制处理。

## 十四、路由器结构

视频区分：

### 控制平面

负责：

- 路由算法
- 生成/维护路由表
- 控制整个网络层转发行为

### 数据平面

负责：

- 按转发表对到达分组进行高速转发

因此：

- “算路”主要在控制平面。
- “按表转发”主要在数据平面。

视频也强调路由器能够隔离广播域，并将路由/转发的控制逻辑和实际高速数据转发分开理解。

## 十五、SDN / OpenFlow

传统网络中，每台路由器都同时包含控制和转发功能；SDN 将控制逻辑集中到控制器，把交换设备重点放在数据平面。

### OpenFlow 的 match-action 思想

流表核心是：

- **匹配**
- **动作**

匹配字段可以跨多层，例如：

- 入端口
- 以太网字段
- VLAN
- IP
- TCP/UDP

动作可以包括：

- 转发到指定端口
- 丢弃
- 修改/重写字段
- 复制到多个端口

因此一个 OpenFlow 交换机不仅能做传统“目的 MAC → 端口”的二层交换，还可实现防火墙、访问控制、负载均衡等策略。

### SDN 控制器接口

视频展示：

- 北向接口：控制器向上层应用/意图提供能力。
- 南向接口：控制器与数据平面设备通信，OpenFlow 是典型协议。
- 东西向接口：控制器之间协同。

## 十六、后续做题统一判断链

### 主机跨网发送

1. 目的 IP 与掩码 AND。
2. 判断是否同网。
3. 不同网 → 找默认网关。
4. ARP 查默认网关 MAC。
5. 封装链路层帧。
6. 路由器按最长前缀匹配选择下一跳。
7. 每一跳重新封装新的链路层帧。

### 路由协议

- 跳数 + UDP 520 → RIP。
- 链路状态 + LSDB + IP协议号89 → OSPF。
- AS之间 + TCP + AS-PATH → BGP。

### 地址转换

- 只改 IP 映射 → NAT。
- IP + 端口共同映射 → NAPT。

### SDN

- 路由算法集中控制、设备按流表转发 → SDN。
- 匹配字段 + 动作 → OpenFlow。
