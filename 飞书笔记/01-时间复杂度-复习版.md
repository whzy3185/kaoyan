# 数据结构｜视频 1：时间复杂度复习笔记

> 用途：飞书复习版。只保留做题判断链、典型模型、个人易错点。

## 一、统一做题流程

复杂度题固定写四步：

1. 找基本运算：到底数哪条语句。
2. 列变量变化：第 1、2、3…轮是什么值。
3. 用退出条件把轮数 t 与 n 建关系。
4. 多层循环先算“每轮工作量”，最后再求和。

不要看到两层循环就直接写 O(n²)。

## 二、高频模型

### 1. 线性循环

i++ 跑到 n：

O(n)

### 2. 倍增/倍乘

i *= c，c>1：

1,c,c²,...

轮数：

O(log n)

### 3. 累加型

sum += i：

1+2+...+t ≈ t²/2

若 sum<n，则：

t=O(√n)

### 4. 递归

n→n-1：

深度 O(n)

n→n/2：

深度 O(log n)

### 5. 外层倍增，内层跑到 i

工作量：

1+c+c²+... ≈ 最后一项

典型：

O(n)

### 6. 外层 n 轮，内层倍增

n × log n：

O(n log n)

### 7. 两层都倍增且互相制约

每轮：

log n, log n-1, ..., 1

总和：

O((log n)²)

### 8. j += i

第 i 轮约 n/i 次：

n(1+1/2+...+1/n)

O(n log n)

## 三、空间复杂度

只看“同时存在的额外空间”。

- 固定变量：O(1)
- 循环中不断 malloc 且不释放：可到 O(n)
- 递归 n→n-1：O(n)
- 递归 n→n/2：O(log n)

## 四、个人易错点

- i*=c 只说明“外层轮数”可能是 log n，不代表整个程序就是 O(log n)。
- 外层倍增、内层跑到 i，要把 1+c+c²+... 相加，结果通常是 O(n)。
- 外层/内层都倍增但内层起点依赖 i，要列各轮 log n, log n-1,...，结果可能是 O((log n)²)。
- 内层每轮约 log i 次时，总和是 Σlog i = O(n log n)。
