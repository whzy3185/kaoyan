# 数据结构｜视频 2：线性结构复习笔记

> 用途：飞书复习版。按“题型 → 判断动作 → 易错点”整理。

## 一、线性表

### 顺序表

- 按位访问：O(1)
- 第 i 位插入：移动 n-i+1 个
- 删除第 i 个：移动 n-i 个
- 表头删除：移动 n-1 个

### 单链表

已知 p 地址：

- p 后插入：O(1)
- 删除 p 后继：O(1)
- 正常删除 p 本身：通常要找前驱，O(n)

固定动作：

先画 前驱 → 当前 → 后继；先接链，再 free。

## 二、栈与队列

### 栈

后进先出 LIFO。

判断出栈序列：直接模拟，不凭感觉。

### Catalan

固定入栈顺序的合法出栈序列数：

C_n = 1/(n+1) × C(2n,n)

组合数与 Catalan 最终值不要混。

### 受限双端队列

先画允许的入/出方向，再模拟目标序列。

### 队列 + 栈

- 队列：保持原相对顺序
- 栈：局部逆序

只把“经过栈”的那一段反转。

## 三、循环队列

课程常用约定：

front 指队头，rear 指队尾后一个位置。

空一格法：

- 空：rear==front
- 满：(rear+1)%MAXSIZE==front
- 长度：(MAXSIZE+rear-front)%MAXSIZE
- 最大元素数：MAXSIZE-1

num 法：

- 空：num=0
- 满：num=MAXSIZE

tag 法：

front==rear 时：

- tag=0：空
- tag=1：满

做题前先确认题目对 front/rear 的定义。

## 四、表达式

### 后缀求值

从左到右：

- 数字入栈
- 运算符弹两个操作数
- 减法/除法：后弹出的数是左操作数

### 中缀转后缀

- 操作数直接输出
- 左括号直接入栈
- 右括号一直弹到左括号
- 新运算符优先级更高：直接入栈
- 新运算符优先级低于或等于栈顶：先弹栈
- + - * / 同级按左结合处理

个人易错：曾多次把“新运算符与栈顶谁先处理”的方向弄反；复做时必须画运算符栈。

## 五、特殊矩阵

### 对称矩阵

n 阶只存一半含主对角线：

n(n+1)/2

下三角按行、数组从 0 开始：

先数前 i-1 行，再加本行偏移。

### 三对角矩阵

非零元数量：

3n-2

按行压缩：

第 1 行 2 个，中间行通常 3 个，最后一行 2 个。

个人易错：a_43 曾把位置数到 11，实际应先把前三行存储量 2+3+3=8 算清楚。

### 二维数组行优先

A[i][j] 前面的元素数：

i×列数+j

地址：

首地址 + (i×列数+j)×元素字节数

## 六、KMP

### 真前后缀

整个字符串本身不能算真前缀/真后缀。

### next：课程约定

- 数组按课程体系从 0 表示
- 前两项固定 0、1
- 后续位置看“当前位置之前的子串”
- 找最长相同真前后缀，再按课程下标换算

已能独立得到：

AABAB → 0,1,2,1,2

### nextval

- 当前字符 ≠ next 指向字符：保留 next
- 当前字符 = next 指向字符：沿 nextval 继续跳

目的：跳过必然重复失败的比较。

### 实际匹配

失配时：

- 主串 i 不回退
- 模式串 j 按 next/nextval 跳

统计比较次数时，相等与不等的字符比较都算一次。

## 七、个人易错点

- [ ] 已知 p 地址与“还需要找 p”不要混。
- [ ] 顺序表插入/删除移动个数相差 1。
- [ ] 经过栈的部分才逆序。
- [ ] Catalan 的组合数中间值与最终值分开。
- [ ] 中缀转后缀：高/低/同级优先级重新练。
- [ ] 对称/三对角矩阵注意 0/1 下标。
- [ ] 真前后缀不能取整个串。
- [ ] KMP 先确认题目 next 定义，避免混用 -1 起始版本。
- [ ] KMP 比较次数再做完整模拟。
