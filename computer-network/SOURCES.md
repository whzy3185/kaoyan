## OCR / 文本归档规则

仓库中的 `pdf-ocr/` 是学习用的粗 OCR 整理版，不把它当作逐字符校勘版。

处理规则：

1. 以 PDF 页面中可识别的文字、目录和图示为依据。
2. 动画式课件常把同一页逐步加内容，归档时合并重复部分。
3. 图形流程用简短文字描述，避免大量重复占位符。
4. 明确可识别的数字、帧字段长度、协议名称等尽量保留。
5. 公式、下标、希腊字母或图中文字识别不稳时标为“需回原 PDF 核对”。
6. 不根据通用教材常识擅自补写 PDF 没有被确认的原文。
7. 后续做题或背诵固定数值时，优先回原 PDF 页核对。

## 当前限制

当前归档重点是“把 11 份资料都建立成可检索的学习入口，并尽可能 OCR 出可确认内容”。部分长 PDF 的后半部分当前没有逐页完成字符级校勘，因此文件中会保留“待逐页补校”的提示。

如果后续学习命中某个未细校页，应直接回对应 PDF 页重新读取后再讲，不猜原题或原公式。
