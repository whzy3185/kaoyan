这些课件存在大量“同一页逐步出现内容”的动画式重复页，因此整理时按知识点合并。

标记含义：

- **已确认**：当前 PDF 文本/页面可稳定读取。
- **目录确认**：章节名可以确认，但正文未做逐页字符级校勘。
- **需回原 PDF 核对**：公式、符号或图示不适合根据粗 OCR 猜测。
