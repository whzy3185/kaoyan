## 物理层特性

已确认原文：

物理层的主要任务可以描述为确定与传输媒体接口有关的一些特性：

1. **机械特性**：接口所用接线器的形状、尺寸、引脚数目和排列、固定和锁定装置等。
2. **电气特性**：接口电缆各条线上出现的电压范围。
3. **功能特性**：某条线上某一电平电压所表示的意义。
4. **过程特性**：不同功能的各种可能事件的出现顺序。

## 数据通信系统模型

课件图示结构：

输入信息 → 源点 → 发送器 → 传输系统 → 接收器 → 终点 → 输出信息

示例使用“调制解调器—公用电话网—调制解调器”说明数字比特流经过模拟传输系统的过程。

### 源点

已确认：

- 源点设备产生要传输的数据。
- 例子：从计算机键盘输入文字，计算机产生输出的数字比特流。
- 源点也称源站或信源。

### 发送器

已确认：

- 源点产生的数字比特流通常需要经过发送器编码后才能进入传输系统。
- 调制器是典型发送器。
- 课件提到很多计算机使用内置调制解调器，即调制器 + 解调器。

### 接收器

已确认：

- 接受传输系统传来的信号，并转换成目的设备可处理的信息。
- 典型接收器是解调器。
- 解调器从线路上的模拟信号中提取信息，还原发送端的比特信息流。

### 终点

已确认：

- 终点设备从接收器获得传送来的数字比特流并输出信息。
- 例子：计算机显示文字。
- 也称目的站或信宿。

## 模拟信号和数字信号

已确认原文要点：

- 根据代表消息的参数取值方式，信号可分为两类。
- **模拟信号（连续信号）**：代表消息的参数取值连续。
- **数字信号（离散信号）**：代表消息的参数取值离散。
- 使用二进制编码时，可用两种不同码元分别表示 0 和 1 状态。
