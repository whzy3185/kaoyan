## 局域网与广域网

课件给出的局域网主要特点包括：

- 网络为一个单位所有。
- 地理范围和站点数目有限。

按网络拓扑可见图示：

- 星形网
- 环形网
- 总线网

### 局域网 / 广域网对比表

当前可确认表格内容：

| 项目 | 广域网 | 局域网 |
|---|---|---|
| 覆盖范围 | 很广，通常跨区域 | 较小，通常在一个区域内 |
| 连接方式 | 通常采用点对点 | 普遍使用广播信道 |
| OSI 参考模型层次 | 三层：物理层、数据链路层、网络层 | 两层：物理层、数据链路层 |
| 联系 | 二者都是互联网的重要构件；从互联网角度看是平等关系 | 同左 |
| 网内通信 | 主机在该网内通信时只需使用该网络的物理地址 | 同左 |
| 着重点 | 课件表中写“强调资源共享” | 课件表中写“强调数据传输” |

## 适配器的作用

课件用网卡图示说明：

- 计算机内部有 CPU、存储器。
- 计算机内部与适配器之间用并行通信。
- 适配器面向局域网/广域网一侧进行串行通信。
- 计算机负责生成待发送数据、处理收到的数据。
- 适配器负责把帧发送到局域网、从局域网接收帧。
- 图示把适配器对应到物理层和数据链路层。
