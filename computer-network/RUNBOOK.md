# 计算机网络互动教学 Runbook

本文件参考 `probability-theory` 分支，用于后续恢复固定学习方式。

## 1. 总目标

- 范围：当前 11 份计算机网络 PDF。
- 主线：严格按照 PDF 原章节、术语和题型推进。
- 当前范围覆盖计算机网络概述、物理层和数据链路层。
- 目标：先理解概念和机制，再形成考研选择题/计算题的条件反射。

## 2. 单次交互默认结构

新概念第一次出现时：

1. 定义。
2. 符号和术语解释。
3. 直观过程。
4. 为什么这样设计。
5. 什么时候考。
6. 一个最小例子。
7. 让学习者完成一个关键判断。

已经学过的内容进入练习时：

- 给完整题面。
- 先让学习者判断协议、时延、窗口、帧结构或设备行为。
- 回答后精确指出哪一步对、哪一步错。
- 纯机械计算可以由助手接手。

## 3. 资料优先级

1. 对应 PDF 原页。
2. `pdf-ocr/` 的整理文本。
3. 同目录其他 PDF 中明确重复出现的定义。
4. 只有用户要求补充时，才加入教材外知识，并标“补充理解”。

遇到 OCR 乱码、公式不完整、图示信息缺失时，必须回原 PDF 核对，不猜。

## 4. 高频判断链

学习时优先建立这些判断：

- 设备工作层次 → 能否隔离冲突域/广播域 → 转发依据是什么。
- 停止等待/滑动窗口 → 发送周期 → 信道利用率。
- MAC 协议 → 信道是否先监听 → 碰撞后怎么处理。
- 交换机收到帧 → 先学习源 MAC → 再查目的 MAC → 转发/过滤/泛洪。
- VLAN → 逻辑广播域 → 802.1Q 标记。
- PPP → 点对点 → 帧定界/透明传输/差错检测 → LCP/NCP。

## 5. 公式与计算题

重要公式单独展示并说明变量含义。

信道利用率题必须先画时间结构或明确：

- 数据帧发送时延。
- 单向传播时延。
- RTT。
- ACK 发送时延是否忽略。
- 窗口内可连续发送多少帧。

不直接套公式到最后一步。

## 6. 每日进度

每次学习可在 `PROGRESS.md` 中更新：

- 当前 PDF。
- 当前页/章节。
- 已掌握点。
- 易错点。
- 下一恢复点。

完成一份 PDF 后再进入下一份，除非用户主动跨章节。
