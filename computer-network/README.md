## OCR 归档

所有资料的可检索整理版放在：

`pdf-ocr/`

当前归档采用“粗 OCR + 去重整理”方式：

- 保留 PDF 原章节顺序和术语。
- 连续动画页、重复图示页合并，不机械重复相同文字。
- 能稳定识别的定义、公式结构、例题条件和结论尽量保留。
- 图示改写为文字说明。
- OCR 不可靠、公式乱码或当前无法逐页核验的地方明确标记，不凭常识猜原文。
- 这批文件用于检索和学习导航；精确题面、公式符号仍应回原 PDF 核对。
