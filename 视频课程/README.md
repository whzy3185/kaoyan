## 使用原则

- 视频中的讲题方法、术语和板书思路优先保留。
- 与现有 PDF 讲义配合使用：视频负责“怎么判断、怎么做题”，PDF 负责系统知识框架。
- 视频中出现的真题/练习按知识点归档，但不把课程答案直接写入 408 真题分支，避免提前泄题。
- 后续继续上传同系列视频时，按编号追加并同步到本索引。
