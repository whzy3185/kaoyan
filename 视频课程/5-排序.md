# 5-排序

> 来源：视频《5-排序.mp4》，时长约 2 小时 38 分 04 秒。

本视频按三个考点展开：

1. 内部排序思想；
2. 内部排序总结；
3. 外部排序。

课程重点不是只背复杂度，而是通过“每一趟到底做了什么、哪些元素位置已经确定、初始序列如何影响比较/移动/趟数”来识别排序算法。

## 考点 1：内部排序思想

### 1. 直接插入排序

视频用“哨兵位”演示直接插入排序。

基本过程：

1. 将待插入元素暂存到哨兵位置；
2. 从已有序序列末尾向前比较；
3. 比待插入元素大的记录依次后移；
4. 找到插入位置后，把哨兵中的元素放回腾出的空位。

做题时要抓住两个区域：

- 前面是已有序区；
- 后面是待排序区。

每一趟只把当前一个元素插入前面的有序区。

### 2. 折半插入排序

视频强调：折半插入只优化“查找插入位置时的比较次数”，元素移动仍然不可避免。

课程总结：

- 在已有序区中使用折半查找定位插入位置；
- 每一趟比较次数可以降到对数级；
- 但元素移动次数并没有因此消失；
- 因而整体平均时间复杂度仍然保持平方数量级；
- 只适用于顺序存储结构。

真题识别信号：

- “比较次数变少、移动次数基本不变”；
- “直接插入与折半插入比较”。

### 3. 希尔排序

视频把希尔排序解释为“按增量分组 + 各组直接插入”。

过程：

1. 取一个增量 dk；
2. 相隔 dk 的元素划到同一子表；
3. 对每个子表分别做直接插入排序；
4. 逐步缩小 dk；
5. 最后一趟增量为 1，相当于对整体再做一次直接插入排序。

课程特别提醒：

- 分组看的是“下标间隔”；
- 同一组元素在原数组中通常并不连续；
- 做题时先根据 dk 把组画出来，再在组内插入。

### 4. 冒泡排序

视频在内部排序总结与“一趟结果”类真题中使用冒泡排序作为典型比较对象。

识别核心：

- 相邻元素比较和交换；
- 一趟会把一个极值送到最终位置；
- 若采用提前终止优化，某一趟没有交换时可以结束。

### 5. 快速排序

视频用左右指针和枢轴元素演示一趟划分。

基本过程：

1. 选择一个枢轴元素；
2. low、high 从两端向中间移动；
3. high 从右向左寻找比枢轴小的元素；
4. low 从左向右寻找比枢轴大的元素；
5. 双指针相遇后，枢轴落到最终位置；
6. 对枢轴左右两个子表递归重复。

视频强调：

- 一次划分至少确定一个元素的最终位置，即枢轴；
- 每次选择的 pivot 若把序列分得越均匀，递归树越矮；
- 最坏情况递归深度可达到 n，较理想时接近 log n；
- 快排依赖随机访问，更适合顺序存储。

做真题时常从“第 1 趟 / 第 2 趟结果”反推某序列能否由快排产生。

### 6. 简单选择排序

每一趟：

1. 在当前无序区中找到最小元素；
2. 与无序区第一个元素交换；
3. 无序区向后缩一位；
4. 重复直到全部有序。

课程把它作为“每一趟确定一个元素最终位置”的典型算法。

关键特征：

- 每趟都要完整扫描剩余无序区；
- 比较次数受初始序列状态影响很小；
- 交换次数与比较次数要分开看。

### 7. 堆排序

视频以大根堆为例，分别讲“建堆、调整、删除堆顶”。

#### 建堆

- 从最后一个分支结点开始；
- 根与较大的孩子比较；
- 不满足大根堆时向下调整；
- 从后向前依次处理所有分支结点。

视频提醒：如果某次下沉影响了下面已经调整过的子树，要继续向下恢复堆性质。

#### 删除堆顶 / 排序

1. 堆顶与堆底元素交换；
2. 缩小当前堆的有效范围；
3. 从根开始向下调整；
4. 新堆顶重新成为当前最大值。

板书特别说明：

- 左右孩子关键字相同时，按课程实现选择左孩子与父亲比较/交换；
- 堆可按完全二叉树的顺序结构理解。

### 8. 归并排序

课程用二路归并的“分—合”过程画递归树。

关键点：

- 分解和合并是两个对称过程；
- 分到足够小的子序列后再逐层合并；
- 写代码时不一定只合并原数组中最初相邻的两个块，要看当前递归区间。

真题常问：

- 已知第一趟二路归并后的若干长度为 2 的有序表，第二趟结果是什么；
- 某个中间序列是否可能是归并排序的阶段结果。

### 9. 基数排序

视频的内部排序总结表把基数排序作为非比较型排序纳入统一比较。

刷题时重点关注：

- 按位进行多趟“分配—收集”；
- 总复杂度与关键字位数 d、记录数 n、基数 r 有关；
- 额外空间与桶/队列数量相关。

## 考点 2：内部排序总结

视频用多张总结表把排序算法放在同一框架比较。

### 1. 时间复杂度与空间复杂度

课程总结表覆盖：

- 直接插入排序；
- 冒泡排序；
- 简单选择排序；
- 快速排序；
- 堆排序；
- 归并排序；
- 基数排序。

其中重点反复强调：

- 直接插入、冒泡在最好情况下可以达到线性级；
- 简单选择排序的比较工作量基本固定；
- 快速排序平均为 n log n 级，最坏可退化为平方级；
- 堆排序和归并排序保持 n log n 级；
- 快排的辅助空间来自递归栈，和划分是否均匀有关；
- 归并排序需要与问题规模同阶的辅助空间；
- 基数排序的复杂度表达式要保留 d、n、r 三个量。

### 2. 与初始序列状态的关系

视频单独把“初始序列状态是否影响时间、比较次数、趟数”拿出来做判断题。

做题时不要只问“这个算法复杂度多少”，还要拆成：

- 比较次数会不会因初始有序程度改变；
- 移动次数会不会改变；
- 总趟数会不会改变；
- 是否使用了提前结束优化。

课程总结中明确把以下算法作为“整体时间复杂度与初始序列状态无关”的重点：

- 简单选择排序；
- 堆排序；
- 归并排序；
- 基数排序。

### 3. 一趟后能否确定最终位置

视频把“每一趟是否至少确定一个元素最终位置”作为高频判断维度。

重点算法包括：

- 冒泡排序；
- 简单选择排序；
- 快速排序；
- 堆排序。

刷题时看到“一趟结束后某个元素是否已经在最终位置”要优先想到这一组。

### 4. 比较次数是否依赖初始状态

课程总结表专门区分“比较次数与序列初始状态无关”的情况，并结合折半插入、未优化冒泡、简单选择、归并和基数排序进行说明。

这里要特别注意：

- “比较次数不变”与“总时间不变”不是同一个判断；
- “数量级相同”与“精确比较次数完全相同”也要区分；
- 折半插入虽然比较次数得到优化，元素移动仍受插入位置影响。

### 5. 排序过程识别题

视频使用 2009、2015、2019 等真题训练：

- 根据中间序列判断是哪一种排序；
- 判断某序列是否可能成为快排第 2 趟结果；
- 堆删除堆顶后统计比较次数；
- 二路归并第 2 趟的可能结果。

固定做法：

1. 先寻找该算法“一趟后的结构特征”；
2. 标出已经确定最终位置的元素；
3. 检查剩余区域是否仍满足该算法的局部约束；
4. 不要只凭“看起来更有序”判断。

## 考点 3：外部排序

### 1. 为什么需要外部排序

当待排序记录数量很大、无法一次全部装入内存时，排序必须借助外存。

视频把外部排序分成两步：

1. **通过内部排序得到初始归并段**：分批将外存数据调入内存，分别排序后写回外存；
2. **将初始归并段逐趟归并**：使有序段逐步变长，最终得到完整有序文件。

课程强调：外部排序真正昂贵的是外存读/写。

### 2. 归并趟数

若有 m 个初始归并段，采用 k 路平衡归并，课程给出归并趟数：

s = ceil(log_k m)

因此减少 I/O 的核心方向之一是减少归并趟数。

### 3. 增大归并路数 k

增大 k 可以降低归并趟数，但会带来新的问题：

- 同时维护更多归并段；
- 直接比较 k 路当前最小记录会增加内部比较成本。

视频随后引入 **败者树**，用于降低多路归并时选取当前最小记录的比较代价。

### 4. 败者树

课程用锦标赛式树形展示败者树。

理解重点：

- 叶端对应各归并段当前记录；
- 内部结点记录比较中的“败者”；
- 根位置保留最终胜者对应信息；
- 输出一个记录后，只需沿该记录所在路径重新比赛，不必重新比较全部 k 路。

败者树的作用是：在增大归并路数时，控制内部比较开销。

### 5. 减少初始归并段个数

另一条优化路线是让每个初始归并段更长，从而减少 m。

视频引入 **置换-选择排序**：

- 内存工作区装入一批记录；
- 每次选择当前可继续接到本归并段末尾的最小记录输出；
- 新读入记录若还能接在当前归并段后，则继续参加本段选择；
- 若关键字过小、不能接到当前段，则被冻结到下一初始归并段。

课程后段用 2023 年 408 真题完整演示工作区、输入记录和输出归并段的变化。

### 6. 最佳归并树

当各初始归并段长度不等时，归并次序会影响总 I/O 次数。

视频把它与哈夫曼树联系起来：

- 初始归并段长度作为叶结点权值；
- 每次优先合并较短的归并段；
- 目标是使带权路径长度最小，从而减少总读写量。

对于严格 k 叉归并树，课程使用：

n0 = (k-1)nk + 1

判断是否需要补虚段。

若叶结点数不能满足严格 k 叉树条件，则补长度为 0 的虚归并段，再构造最佳归并树。

## 外部排序优化判断链

看到外部排序优化题，先问两件事：

1. **归并趟数能不能减少？**
   - 增大归并路数 k；
   - 结合败者树降低 k 路选择最小记录的内部比较成本。

2. **初始归并段个数 m 能不能减少？**
   - 使用置换-选择排序产生更长初始归并段；
   - 对不等长归并段再使用最佳归并树优化合并次序。

最终目标统一落到：**减少外存 I/O 次数**。

## 需要形成条件反射

- 直接插入 → 哨兵 + 有序区向前比较 + 元素后移。
- 折半插入 → 比较次数下降，移动仍在。
- 希尔 → 先按 dk 分组，组内直接插入，最后 dk=1。
- 快排 → 枢轴 + low/high；一趟确定枢轴最终位置。
- 简单选择 → 每趟在无序区找最小值。
- 堆排 → 完全二叉树；建堆从最后分支结点向前，删除堆顶后从根向下调整。
- 归并 → 分、合对称；阶段结果要按当前子区间判断。
- 外部排序 → 初始归并段 + 多路归并。
- 增大 k → 趟数减少，但要考虑败者树。
- 减少 m → 置换-选择。
- 不等长初始段 → 最佳归并树 / 哈夫曼思想。
- 外排最终优化目标 → I/O 次数。
