# 4-查找

> 来源：视频《4-查找.mp4》，时长约 3 小时 43 分。

本视频按“线性表的查找 → BST → AVL → B树/B+树 → 散列表 → 红黑树”推进，重点放在考研选择题的判定方法和树形调整过程。

## 考点 1：线性表的查找

课程先从顺序查找和折半查找进入平均查找长度 ASL。

### 顺序查找

做题时直接按“比较了几个关键字”统计查找长度。

视频会区分：

- 查找成功；
- 查找失败。

计算平均查找长度时，要先确认每个关键字是否等概率，题目如果给出不同查找概率则按概率加权。

### 折半查找

视频大量使用“判定树”理解折半查找。

固定思路：

1. 中间元素作为当前比较结点；
2. 小于当前关键字进入左半区；
3. 大于当前关键字进入右半区；
4. 继续递归划分；
5. 查找长度等于在判定树中经历的比较次数。

### 折半查找 ASL

课程把成功 ASL 与判定树层数联系：

- 第 1 层结点比较 1 次；
- 第 2 层比较 2 次；
- 依次类推；
- 按各层结点数加权求平均。

查找失败时则要看外部失败位置 / 区间对应的比较次数。

### 判定树类题

视频真题训练的重点包括：

- 给定一个二叉树，判断是否可能是折半查找判定树；
- 根据有序表长度判断树的高度；
- 判断某个查找序列是否可能由折半查找产生；
- 求成功或失败的最大比较次数。

## 考点 2：二叉排序树 BST

课程通过“查找路径”反推关键字约束。

### 基本性质

对于 BST：

- 左子树中的关键字小于当前结点；
- 右子树中的关键字大于当前结点；
- 中序遍历可得到有序序列。

### 查找路径题

视频会在树上逐步画出当前允许的关键字范围。

从根开始：

- 向左走 → 新关键字必须落在更小的范围；
- 向右走 → 新关键字必须落在更大的范围；
- 之前祖先结点形成的上下界仍然有效。

因此判断一串关键字是否可能构成 BST 查找路径时，要维护“当前允许区间”，不能只比较相邻两个数。

### 插入与删除

课程通过树形演示插入后位置由比较路径唯一决定。

删除题重点关注：

- 叶结点；
- 只有一个孩子；
- 有两个孩子时的替代与重新连接。

视频还用“删除某结点后再插回”类型的真题判断最终树形是否一定恢复。

## 考点 3：AVL

### 平衡因子

视频用左右子树高度差判断结点是否平衡。

课程反复检查：

- 哪个结点首先失衡；
- 失衡结点的哪一侧更高；
- 新插入关键字又落在较高子树的哪一侧。

### 四种调整

视频用图形总结四类：

- LL；
- RR；
- LR；
- RL。

做题判断链：

1. 找离新插入结点最近的失衡祖先；
2. 判断失衡方向；
3. 再看新结点位于较高子树的左侧还是右侧；
4. 选择单旋或双旋；
5. 调整后重新检查根和各子树高度。

### 高度与最少结点数

课程还用递推思想处理“给定高度的 AVL 至少有多少结点”。

关键是让左右子树高度尽可能相差 1，同时各自又都取该高度下的最少规模。

### 真题风格

- 连续插入一串关键字，求最终根；
- 删除后再插回，判断树是否一定恢复；
- 给出若干 AVL 图形，判断哪个满足条件；
- 根据高度或结点数判断可能性。

## 考点 4：B树和 B+树

视频先用表格整理 B树与 B+树的基本性质，再通过插入、删除真题画调整过程。

### m 阶 B树数量关系

课程重点围绕：

- 一个结点最多可有多少孩子；
- 最多 / 最少关键字数；
- 根结点与非根结点的下限不同；
- 关键字数与孩子数之间存在固定对应关系。

做题时先确认题目所用“m 阶”的定义，再写上下限。

### B树查找

在结点内部先比较关键字：

- 命中则成功；
- 未命中时根据关键字所在区间选择对应孩子指针；
- 再进入下一层。

### 插入

视频板书会把一个结点关键字写满后再继续插入，随后演示：

1. 当前结点发生溢出；
2. 中间关键字上移到父结点；
3. 左右关键字分裂成两个结点；
4. 父结点若继续溢出则向上重复；
5. 根分裂时树高增加。

### 删除

删除后若关键字数量低于下限，视频按情况处理：

- 向相邻兄弟借关键字；
- 通过父结点关键字完成旋转式调整；
- 兄弟也不足时与兄弟合并；
- 合并可能继续向父层传播。

课程用 2022 年删除 B树关键字真题逐步画树形变化。

### B+树

视频通过表格比较 B树和 B+树。

板书强调 B+树的叶结点层保存完整关键字信息，并通过叶层链接支持顺序访问；内部结点主要承担索引作用。

做题时需要区分：

- 关键字在非叶结点是否代表完整记录；
- 叶结点之间是否有顺序链接；
- 查找最终是否必须到叶层。

## 考点 5：散列表

### 基本概念

视频整理：

- 散列函数；
- 散列地址；
- 冲突；
- 同义词；
- 装填因子。

课程强调 ASL 与“表长”不是简单一一对应，要结合装填情况与冲突处理方式。

### 链地址法

发生冲突的关键字挂在同一桶对应的链表中。

做题时：

1. 先按散列函数算初始地址；
2. 同一地址的关键字进入同一链；
3. 查找长度按链内比较次数计算。

### 线性探测法

发生冲突时沿表向后逐格尝试，必要时循环回表头。

视频真题会逐个插入关键字，最后计算：

- 成功 ASL；
- 失败 ASL。

失败查找长度需要按“从某个散列地址出发直到遇到真正空位置”为止统计，不能只看已存关键字。

### 平方探测法

视频还展示平方探测的探测序列。

做题时必须按题目给定公式逐项生成候选地址，不能把它和线性探测混用。

### ASL 题固定流程

1. 先画完整散列表；
2. 对每个成功关键字写出比较次数；
3. 对每个可能散列入口写出失败比较次数；
4. 分别求平均；
5. 题目若不是等概率，按给定概率加权。

## 考点 6：红黑树

视频最后讲红黑树，并通过插入示意图训练颜色调整和旋转。

### 基本性质

课程围绕以下约束判断树是否合法：

- 结点具有红/黑颜色；
- 根结点按规则保持黑色；
- 红结点不能连续相邻；
- 从同一结点到各叶端的路径具有一致的黑色结点数量。

视频用 black height（黑高）辅助分析红黑树高度和路径。

### 插入调整

新插入结点先按 BST 规则找到位置，再根据父结点、祖父结点、叔叔结点的颜色决定调整。

板书重点区分：

- 叔叔结点为红色时的重新染色；
- 叔叔结点为黑色时，根据新结点、父结点和祖父结点的位置关系做旋转与染色；
- LL、RR 与 LR、RL 形态的处理方向不同。

### 做题方式

1. 先按 BST 插入；
2. 找父、祖父、叔叔；
3. 判断颜色；
4. 决定“染色”还是“旋转 + 染色”；
5. 调整后继续向上检查是否产生新的冲突；
6. 最后保证根结点满足规则。

## 本视频需要形成的判断链

- 折半查找 → 先画判定树，ASL 看层数。
- BST 查找路径 → 全程维护上下界，不能只比较相邻结点。
- AVL → 找最近失衡祖先 → 判断 LL/RR/LR/RL → 旋转。
- B树插入 → 溢出 → 分裂 → 中间关键字上移。
- B树删除 → 低于下限 → 先借，借不到再合并。
- 散列表 → 先构造完整表，再算成功 / 失败 ASL。
- 红黑树插入 → BST 定位 → 看父/叔颜色 → 染色或旋转。
