# 2-线性结构

> 来源：视频《2-线性结构.mp4》，时长约 3 小时 47 分 47 秒。

课程按“考点”组织，核心覆盖线性表、栈与队列、卡特兰数、循环队列、栈的应用、特殊矩阵和 KMP。

## 考点 1：线性表的基本操作

### 顺序表、链表、静态链表比较

视频用表格比较四类基本操作：

- 按位查找；
- 按值查找；
- 插入；
- 删除。

关键判断：

- 顺序表支持随机访问，按位查找是常数级；
- 链表按位查找需要沿结点逐个走；
- 顺序表插入、删除常伴随大量元素移动；
- 链表插入、删除本身改指针很快，但找到目标位置或前驱结点仍可能需要遍历；
- 静态链表虽然存储在数组中，但逻辑关系靠“游标/链接”维持，访问特点仍更接近链表。

### 链表指针题

视频重点训练“先画结点，再改指针”。

典型题包括：

- 双向循环链表删除 p；
- 带尾指针的单循环链表删除首元结点；
- 删除双向循环链表中 p 的前驱结点；
- 链式栈 push 时新结点和 top 的连接次序。

做题固定流程：

1. 明确 p、q、pre、next 当前指向谁；
2. 画出前驱—当前—后继；
3. 先保证剩余链表不断链；
4. 最后释放被删除结点；
5. 若有尾指针、头结点，额外判断“只剩一个数据结点”等边界。

## 考点 2：栈和队列的基本操作

### 栈的出栈序列

视频用 2011 年等题讲：

- 固定入栈次序；
- 元素可以停留，也可以随时出栈；
- 通过模拟栈顶判断某前缀是否合法。

课程倾向用“画竖直栈 + 逐个模拟”，避免纯背结论。

### 受限双端队列

若一端只允许入队、另一端允许入队和出队：

- 先把允许操作方向画成一条线；
- 逐个尝试目标出队序列；
- 一旦某元素必须从禁止端出去，就判不可能。

### 队列 + 栈组合

遇到“队列元素可直接输出、也可进入栈、栈再输出”的题：

- 利用队列保持原相对次序；
- 栈负责局部逆序；
- 用目标输出序列反推每个元素走哪条路径。

## 考点 3：卡特兰数

视频把两类问题放到同一个卡特兰模型：

1. n 个元素按固定次序入栈，有多少种合法出栈序列；
2. 先序序列由 n 个互异元素组成时，可对应多少种不同二叉树结构。

使用公式：

C_n = 1/(n+1) × C(2n,n)

课程重点是先识别“合法括号/入栈出栈/二叉树结构”这一类计数模型，再决定是否套卡特兰数。

## 考点 4：假溢出和循环队列

### 假溢出

顺序队列随着 front、rear 向后移动，前面已经出队的位置可能空着，但 rear 到数组末尾后仍无法继续入队，这就是假溢出。

解决思路：把数组逻辑上首尾相接，构成循环队列。

### 区分队空和队满的三种方案

视频列了三种常见方法：

1. 牺牲一个存储单元；
2. 设置 tag，删除后置 0、插入后置 1；
3. 设置 num 记录队列元素个数。

### 常见 front / rear 约定

视频使用的一种典型约定：

- front 指向队头元素；
- rear 指向队尾元素的下一个位置。

在“空一个单元”的方案下：

- 队空：rear == front
- 队满：(rear + 1) % MAXSIZE == front
- 队长：(MAXSIZE + rear - front) % MAXSIZE

题目如果重新定义了 front/rear 含义，要按题面重新推，不能机械套公式。

### 2019 队列设计综合题

课程重点讲了：

- 初始队列为空；
- 允许动态增加占用空间；
- 出队后的空间可重复使用；
- 已占用总空间只增不减；
- 入队、出队保持 O(1)。

讲解通过循环链式结构画出 front/rear 的变化，先统一“队空”状态，再逐个画入队、出队后的指针。

## 考点 5：栈的应用

### 表达式求值

视频把中缀、后缀、前缀放在同一张表中比较。

#### 中缀表达式

通常从左到右扫描，需要：

- 运算数栈；
- 运算符栈。

遇到运算符时比较优先级，必要时弹出已有运算符并计算。

#### 后缀表达式

从左到右扫描：

- 数字直接入栈；
- 遇运算符，弹出两个操作数计算；
- 结果重新入栈。

#### 前缀表达式

从右到左扫描，处理逻辑与后缀对称。

### 中缀转后缀

核心仍是运算符栈：

- 操作数直接输出；
- 运算符按优先级弹栈；
- 左括号入栈；
- 遇右括号一直弹到左括号。

视频用 2012 年题型统计转换过程中“栈内运算符最多同时有多少个”。

### 递归与调用栈

视频用 fact(3) 画调用栈，强调每次函数调用都形成一个栈帧，递归返回时再逐层出栈。

## 考点 7：特殊矩阵

### 稀疏矩阵

课程展示：

- 三元组表示法：记录行、列、值；
- 十字链表：行、列方向都能链接非零元。

### 三对角矩阵压缩

典型题：100 阶三对角矩阵按行优先依次压入一维数组，求 m[i][j] 对应下标。

做法：

1. 先算前 i-1 行一共压了多少元素；
2. 再加第 i 行内的相对位置；
3. 注意数组下标从 0 还是 1 开始。

### 二维数组地址计算

视频用 2021 年题说明：

- 行优先存储；
- 由 A[0][0] 和 A[3][3] 的地址关系反推列数；
- 再计算 A[5][5] 的地址。

### 对称矩阵压缩

上三角/下三角压缩要先明确：

- 按行还是按列；
- 是否含主对角线；
- B[0] 对应哪个元素。

再用等差求和计算前面已经存了多少元素。

## 考点 8：KMP 的 next 与 nextval

### next 数组

视频采用的一套记法：

- next 数组从 0 开始表示；
- 前两位固定为 0、1；
- 从第 3 个字符开始，看“该字符之前的子串”；
- 找最长相等真前缀与真后缀；
- next 值等于该长度再按课程下标体系换算。

视频同时提醒：

- 单个字符本身不能作为自己的前后缀；
- 前缀和后缀不能是整个子串；
- 有些教材用 -1 起始，本质只是整体下标约定平移，要先看题目采用哪一种。

### nextval

课程规则：

1. 先求 next；
2. 逐位比较当前模式字符与 next 指向位置的字符；
3. 若二者不同，本位 nextval 直接取 next；
4. 若二者相同，继续沿 nextval 跳，避免重复比较。

### KMP 模拟

视频通过主串与模式串的错配位置演示：

- i 不回退；
- j 按 next / nextval 调整；
- 统计字符比较次数时，每一次相等或不等的字符比较都要计数。

## 课程做题风格

- 指针题：先画图，后写语句。
- 栈队列题：按操作序列逐步模拟，不靠想象。
- 循环队列：先确定 front/rear 语义，再写判空判满。
- 矩阵压缩：先数“前面已经存了多少”，再算当前偏移。
- KMP：先统一下标体系，再求 next；不要混用两套教材定义。
