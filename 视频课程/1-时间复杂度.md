# 1-时间复杂度

> 来源：视频《1-时间复杂度.mp4》，时长约 57 分 36 秒。

## 课程主线

视频把时间复杂度题统一成三步：

1. **确定基本运算**：到底在数哪条语句执行多少次。
2. **找出变化规律**：把变量在第 1、2、3、… 次循环中的值列出来。
3. **联系跳出条件**：用循环终止条件把执行次数 t 和 n 建立关系，再取数量级。

课程反复强调：复杂循环先不要凭感觉看层数，先把“第几轮 → 变量值 → 退出条件”写出来。

## 题型 1：单层循环

### 倍增 / 倍乘型

典型结构：

- 初值固定；
- 每次执行后乘 2、乘 3 等；
- 条件形如 x < n、x < n/2。

处理方法：设循环执行 t 次，把 x 写成指数形式，再代入退出条件。

视频用 2011 年 408 的 x = 2; while (x < n/2) x = 2*x; 说明：

- x 的变化是 2、2²、2³、…；
- 核心是把第 t 次的 x 与 n/2 联系起来；
- 最终只关心 t 关于 n 的数量级。

同一套路可迁移到“每次乘 3”“平方约束”等变式。

### 累加型

视频用 2017 年题型说明：

- sum += ++i 时，第 t 轮后 i=t；
- sum 形成 1+2+…+t；
- 通过 sum < n 联立求 t 的数量级。

识别信号：循环条件看的变量与每轮增长变量不是同一个量，需要先写出累计和。

## 题型 2：递归

视频以 2012 年阶乘递归为例。

判断递归复杂度时：

- 每层除递归调用外只有常数级工作；
- 参数每次减 1；
- 递归深度就是主要执行次数。

课程处理方式是直接画调用链：fact(5) → fact(4) → fact(3) → …。

重点是数函数调用层数。

## 题型 3：for 循环嵌套

视频强调“**层层制约**”，不能看到两层循环就直接写 O(n²)。

### 外层倍增、内层跑到 i

典型结构：

- 外层 i = 1, 2, 4, 8, …；
- 第 1 轮内层做 1 次；
- 第 2 轮做 2 次；
- 第 3 轮做 4 次；
- …

总次数是 1 + 2 + 4 + …，应直接看几何级数总和的数量级。

### 外层线性、内层倍增

视频练习中出现：

- 外层做 n 轮；
- 每一轮内层按 2 倍增长；
- 单轮内层是 log n 级别；

总复杂度再按实际执行次数合并。

### 交错 / 变步长嵌套

课程后半段用“第 1 轮、第 2 轮、第 3 轮……”逐轮列 j 的起点和执行次数，判断最后一次内层循环的规模。

固定动作：

1. 先列外层第几轮；
2. 再列本轮内层的初值；
3. 写出本轮执行次数；
4. 对所有轮次求和或找主导项。

## 需要形成条件反射

- i *= c → 指数增长，次数通常与 log n 有关。
- sum += i → 先写前若干项和，再联立退出条件。
- 递归参数每次减 1 → 先看递归深度。
- 多层循环 → 先判断内层上界是否依赖外层变量。
- 出现 1+2+4+... → 用几何级数看最后一项量级。
- 出现“每轮都是 log n 次”且外层 n 轮 → 再考虑 n log n。
