# 3-非线性结构（上）

> 来源：视频《3 非线性结构(上).mp4》，时长约 3 小时 14 分 33 秒。

本视频集中在树与二叉树，包括树形数量推断、存储、遍历、线索二叉树、树/森林与二叉树转换、哈夫曼树与前缀编码。

## 考点 1：树形推断

### 结点数与度的关系

视频首先整理：

- 总结点数：N = n0 + n1 + n2 + ... + nm
- 非空树边数：E = N - 1
- 从“孩子总数 = 边数”可得到另一组关于各度结点数量的等式。

做题时常把两式相减，用已知各度结点数求叶结点数。

### m 叉树与满 m 叉树

课程强调：

- 第 i 层最多有 m^(i-1) 个结点；
- 高度为 h 的满 m 叉树总结点数是等比数列和；
- 已知叶结点、非叶结点时，要区分“普通 m 叉树”“满 m 叉树”“正则 k 叉树”。

### 正则 k 叉树

若每个非叶结点都恰有 k 个孩子：

N = n0 + nk = k×nk + 1

从而：

n0 = (k-1)nk + 1

视频用 2016 年综合题反复训练这个式子，并继续讨论给定高度时总结点数的最大值和最小值。

### 完全二叉树

视频整理完全二叉树常用结论：

- 按层序编号 1,2,...,n；
- i 的左右孩子编号分别与 2i、2i+1 相关；
- 最后一层从左向右连续；
- 度为 1 的结点最多只有一个；
- 根据总结点数可以判断树高；
- 叶结点通常集中在最后两层。

题目常见问法：

- 给 n 求叶结点数；
- 给叶结点数求可能的最大高度；
- 给某层叶结点数推整棵树最大/最小规模。

### 树越高 / 越矮

视频用“每层结点尽量少”和“每层尽量多”来判断：

- 同样总结点数下最大高度；
- 同样高度下结点数上下界。

## 考点 2：树的存储

### 二叉链表

n 个结点的二叉链表：

- 每个结点有两个孩子指针；
- 总指针域数为 2n；
- 实际边数 n-1；
- 空指针域数量可以由二者相减得到。

课程把这一结论用于大量“空链域数量”题。

### 顺序存储

完全二叉树非常适合顺序存储。

一般二叉树若强行按完全二叉树下标存储：

- 空位置也要保留；
- 树越偏斜，浪费越严重；
- 给定高度时可能出现“结点很少、数组位置很大”的情况。

### 树的双亲表示

视频展示数组中同时保存：

- 结点数据；
- 双亲下标。

根结点双亲标记为特殊值（如 -1），其余结点通过下标找到父结点。

题目会要求根据双亲数组恢复树，或判断某种说法是否正确。

## 考点 3：唯一确定一棵二叉树

课程强调：要唯一确定二叉树，需要一种遍历确定根的位置，同时配合中序把左右子树切开。

视频展示了：

- 先序 + 中序；
- 后序 + 中序；
- 中序 + 层序。

只给先序 + 后序通常不能唯一确定普通二叉树。

做题固定步骤：

1. 用先序首元素 / 后序末元素 / 层序中最先出现的根确定根；
2. 在中序中找到根；
3. 中序左边是左子树，右边是右子树；
4. 对左右子树递归处理。

## 考点 4：遍历和线索二叉树

### 递归遍历

视频从递归框架讲先序、中序、后序。

每个结点在递归过程中会“经过”多次：

- 第一次到达；
- 左子树处理完返回；
- 右子树处理完返回。

先/中/后序只是在这几个时机中选择何时输出当前结点。

### 非递归遍历

课程重点画栈：

- 先序：访问结点时输出，沿左链压栈，再回退处理右子树；
- 中序：一路压左孩子，弹栈时输出，再转向右子树。

做题时先画“p 当前在哪、栈里有哪些祖先”，再模拟。

### 线索二叉树

结点增加：

- lTag
- rTag

用来区分孩子指针与前驱/后继线索。

课程强调线索化是物理结构改变，空孩子指针会被利用。

中序线索化常用一个 pre 指针保存刚访问过的结点：

- 当前结点左孩子为空时，建立前驱线索；
- pre 的右孩子为空时，建立 pre 的后继线索；
- 最后令 pre = p。

### 线索题判断

视频训练：

- 中序相邻结点之间可能是什么亲属关系；
- 指定结点中序线索化后的左右线索指向；
- 后序/中序等不同线索树不要混淆；
- 题目若给“p、q 在中序序列中相邻”，要结合是否有左右孩子逐项排除。

## 考点 5：树、森林、二叉树

采用“左孩子—右兄弟”转换。

核心观察：

- 树的第一个孩子 → 二叉树左孩子；
- 树中同一父结点的后续兄弟 → 二叉树右孩子；
- 森林中后一棵树的根也通过右兄弟链连接。

因此常见关系题可以直接在转换图上判断。

### 右指针为空结点数量

视频总结：

二叉树中没有右孩子的结点，来自：

- 森林中每棵树的根结点；
- 每个非终端结点的最后一个孩子。

这一结论常用于由树/森林统计转换后二叉树的空右指针数。

### 遍历对应关系

视频用 2019 年题说明：

- 树/森林的遍历与对应二叉树的先、中、后序之间存在固定对应；
- 做题时最好先画一个很小的树转换成二叉树再验证，不建议死背孤立结论。

## 考点 6：哈夫曼树和哈夫曼编码

### 哈夫曼树性质

视频整理：

- n 个叶结点构造二叉哈夫曼树时，会新建 n-1 个内部结点；
- 总结点数为 2n-1；
- 哈夫曼树没有度为 1 的结点；
- 因而 n0 = n2 + 1；
- 权值越小的结点通常离根越远；
- 一组权值可能对应不唯一的哈夫曼树。

### 构造过程

标准步骤：

1. 从当前结点集合中选两个最小权值；
2. 合并为新结点，权值为二者之和；
3. 把新结点放回集合；
4. 重复直到只剩一个根。

视频大量使用“每次圈两个最小值”的方式做题。

### m 叉哈夫曼树补零

视频给出：

设初始叶子数为 n0，先算：

k = (n0 - 1) mod (m - 1)

若 k ≠ 0，需要补若干个权值为 0 的虚结点，使之后每次都能按 m 个结点合并。

### 哈夫曼编码

做编码题时：

1. 先按频率/权值构造哈夫曼树；
2. 左右边分别标 0/1，具体哪边 0、哪边 1 只要统一；
3. 根到叶的路径就是该字符编码；
4. 检查题目给出的编码是否能由某棵哈夫曼树产生。

### 前缀编码

若任意一个字符编码都不是另一个字符编码的前缀，则具有前缀特性。

视频用二叉树/前缀树解释：

- 每个字符应落在叶结点；
- 如果某字符对应的编码结点还有后代，则它就是另一个编码的前缀，不合法。

### 与“最优合并”联系

视频把 2012 年“多个长度不同的有序表两两合并、使总比较次数最小”的题与哈夫曼思想联系：

- 每次优先合并规模最小的两个表；
- 合并后的新规模重新放回；
- 继续选最小的两个。

本质与哈夫曼“反复合并两个最小权值”一致。

## 视频中的纠错提示

课程讲解过程中会直接指出个别板书或口头判断的笔误，并当场修正。后续刷题仍应以原题、PDF 和最终推导为准，不把临时板书当成结论。

## 需要形成条件反射

- 树结点度数统计 → 立刻写 N = 各度结点数之和 和 E=N-1。
- 正则 k 叉树 → 立刻想到 n0=(k-1)nk+1。
- 完全二叉树 → 立刻想到层序编号和最后两层。
- 两种遍历重建 → 看是否含中序。
- 线索化 → 先区分 tag，再区分孩子指针与线索。
- 森林转二叉树 → 左孩子=第一个孩子，右孩子=下一个兄弟。
- 哈夫曼 → 每次抓两个最小；n 个叶结点 → 总结点数 2n-1。
- 前缀编码 → 所有字符必须对应叶结点。
