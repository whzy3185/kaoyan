# 3-非线性结构（下）

> 来源：视频《3-非线性结构(下).mp4》，时长约 3 小时 44 分。

本视频从并查集进入图，覆盖图的基本概念与性质、存储结构、DFS/BFS、拓扑排序、最小生成树、最短路径和关键路径。

## 考点 7：并查集的基本操作

视频用双亲数组和树形图配合解释并查集。

### 基本结构

- 每个集合用一棵树表示；
- 数组项记录当前结点的双亲信息；
- 根结点用特殊值表示；
- Find 用于找到某元素所在集合的根；
- Union 用于合并两个不同集合。

课程讲解时会把“数组内容”和“对应树形”来回转换，因此做题时要同时能看懂两种表示。

### 合并与查找优化

板书中进一步讨论了：

- 合并时尽量把规模较小或高度较低的树接到另一棵树上；
- 查找过程中可压缩从结点到根的路径；
- 优化目标是减少后续 Find 的路径长度。

### 与 Kruskal 的联系

视频直接把并查集用于 Kruskal：

1. 边按权值从小到大考虑；
2. 判断一条边两个端点是否已经在同一集合；
3. 不在同一集合时选入，并把两个集合合并；
4. 已在同一集合时跳过，避免形成回路。

这里是并查集在图算法中的直接应用。

## 考点 8：图的概念和性质

课程用一组基础判断题整理图的常用概念。

重点包括：

- 有向图、无向图；
- 顶点、边 / 弧；
- 度、入度、出度；
- 路径、回路；
- 连通、连通图、连通分量；
- 图中顶点数、边数、度数之间的数量关系。

### 做题方式

遇到“至少多少条边保证连通”“给部分顶点度数求剩余顶点数量”等题时：

1. 先确认有向还是无向；
2. 再确认题目问“存在一种情况”还是“无论如何都保证”；
3. 无向图的度数统计要把每条边对总度数的贡献算清楚；
4. 连通性问题通常要结合“最稀疏”和“最坏断开方式”画图判断。

## 考点 9：邻接矩阵和邻接表

### 邻接矩阵

视频通过矩阵与图互相还原来训练：

- 第 i 行、第 j 列对应顶点 i 到 j 的关系；
- 无向图的邻接矩阵具有对称性；
- 带权图中矩阵元素还可能保存权值；
- 矩阵适合直接统计顶点的度、入度、出度。

### 邻接表

视频把顶点表和边结点画在一起：

- 顶点表保存每个顶点及第一条边的位置；
- 边表按链式结构保存邻接点；
- 同一个图的邻接表顺序并不唯一；
- DFS/BFS 的具体访问序列会受邻接点排列顺序影响。

## 考点 10：十字链表和邻接多重表

课程继续比较有向图、无向图的链式存储。

### 十字链表

用于有向图时，一条弧同时进入：

- 弧尾对应的出边链；
- 弧头对应的入边链。

板书重点展示同一条弧结点如何通过不同指针挂入两条链。

### 邻接多重表

用于无向图时，一条无向边只保存一次，但要同时能挂到两个端点的边链上。

视频通过数组下标和链式连接反复演示如何从图恢复这些指针关系。

## 考点 11：DFS 和 BFS

### DFS

视频先画递归搜索过程：

- 从当前顶点出发；
- 找到一个尚未访问的邻接点继续深入；
- 没有未访问邻接点时回退；
- 通过 visited 数组避免重复访问。

课程还展示了递归 DFS 代码，并结合“把输出语句放在递归调用前或后”分析访问结果的变化。

### BFS

BFS 用队列维持“先发现先扩展”的次序：

1. 起点入队并标记；
2. 队头出队；
3. 扫描其所有未访问邻接点；
4. 新发现顶点标记并入队；
5. 队列空时结束当前连通分量。

### 非连通图

若图不连通，单次从某个起点 DFS/BFS 只能覆盖一个连通分量。

课程代码会在外层继续检查所有顶点，对尚未访问的顶点再次启动遍历。

### 做题提醒

- 遍历序列通常不唯一；
- 邻接点存储顺序会影响最终 DFS/BFS 序列；
- 判断某序列“是否可能”时，应模拟当前可选邻接点；
- 时间复杂度需要结合邻接矩阵或邻接表的存储方式判断。

## 考点 12：拓扑排序

课程用有向无环图说明拓扑序列。

### 基本流程

视频主要采用入度法：

1. 计算每个顶点入度；
2. 选择当前入度为 0 的顶点输出；
3. 删除该顶点发出的边；
4. 相邻顶点入度减 1；
5. 重复直到所有顶点输出或无法继续。

### 判断信号

- 同一 DAG 可能有多个拓扑序列；
- 某一步若同时出现多个入度为 0 的顶点，通常意味着后续选择存在分支；
- 如果还有顶点未输出却再也找不到入度为 0 的顶点，说明图中存在有向环。

视频用真题反复训练“给定序列是不是可能的拓扑序列”和“拓扑序列有多少种”。

## 考点 13：最小生成树

视频并列讲 Prim 和 Kruskal。

### Prim

核心过程是维护“已经进入生成树的顶点集合”：

- 每次在当前集合与外部顶点之间选择权值最小的边；
- 把新顶点和这条边加入生成树；
- 重复直到所有顶点进入。

### Kruskal

- 全局按边权从小到大选边；
- 只有不会与已选边形成回路的边才加入；
- 并查集可以快速判断两个端点是否已经连通。

### 做题重点

- MST 要包含全部顶点；
- 生成树边数固定为 |V|-1；
- Prim 更强调“从当前顶点集合向外扩展”；
- Kruskal 更强调“全局按边权排序”；
- 边权相等时，最小生成树可能不唯一。

## 考点 14：最短路径

视频重点展示 Dijkstra 和 Floyd。

### Dijkstra

用于单源最短路径题时，课程采用 dist 数组：

- 先记录源点到各顶点的当前最短估计；
- 每轮选出一个当前 dist 最小且尚未确定的顶点；
- 用该顶点继续更新其他顶点的 dist；
- 已确定顶点不再返回未确定状态。

真题经常问“第二个被确定的顶点是谁”“执行若干轮后 dist 数组是什么”。

### Floyd

课程用二维矩阵逐步更新任意两点间最短距离。

板书会把“允许经过前 k 个中间顶点”对应到矩阵更新过程。

做题时核心是逐轮比较：

- 原有 i 到 j 距离；
- 经过当前中间顶点后的新距离。

取其中更小者写回矩阵。

## 考点 15：关键路径

视频最后进入 AOE 网和关键路径。

### 事件最早发生时间

从源点向汇点正向计算：

- 一个事件的最早发生时间由所有前驱路径共同约束；
- 取能到达该事件的最大值。

### 事件最迟发生时间

从汇点反向计算：

- 以整个工程总工期为基准向前推；
- 对多个后继约束取更紧的限制。

### 活动的最早 / 最迟开始时间

课程进一步由事件时间计算活动：

- 最早开始时间；
- 最迟开始时间；
- 时间余量。

时间余量为 0 的活动属于关键活动，关键活动组成关键路径。

### 真题判断

视频强调：

- 缩短非关键活动不一定缩短总工期；
- 若要缩短工程总工期，必须关注当前关键路径上的活动；
- 若存在多条关键路径，还需要同时检查其他关键路径是否仍限制总工期。

## 本视频需要形成的判断链

- 并查集 + Kruskal → Find 判断是否成环，Union 合并集合。
- 图的存储 → 先分有向 / 无向，再选矩阵、邻接表、十字链表或邻接多重表。
- DFS → 深入后回退；BFS → 队列逐层扩展。
- 拓扑排序 → 反复找入度 0。
- Prim → 从当前生成树向外找最小边。
- Kruskal → 全局从最小边开始，跳过成环边。
- Dijkstra → 每轮确定一个当前距离最小的未确定顶点。
- Floyd → 逐个放开中间顶点更新二维距离矩阵。
- 关键路径 → 正推最早时间、反推最迟时间、再算余量。
