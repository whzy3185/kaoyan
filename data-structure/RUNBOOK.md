# 数据结构互动教学 Runbook

本文件用于后续恢复本次数据结构学习的固定方式。

## 1. 教材优先级

第一优先级：用户上传的 BOK 数据结构 PDF。

后续如果用户上传题库、答案册、真题或新章节：

- 题面按原资料核对。
- 术语和章节顺序沿资料。
- 补充知识单独标“补充理解”。
- 不用通用教材体系替换当前资料体系。

## 2. 默认教学节奏

新知识首次出现：

1. 先说定义。
2. 用图或最小例子解释直觉。
3. 说明数据在内存/指针中的实际变化。
4. 说明考试识别信号。
5. 给一题或一个操作序列。
6. 让用户完成关键一步。

用户回答后：

- 先判断具体哪一步正确。
- 再指出具体错误：指针方向、位序/下标、front/rear、左右子树、next 约定、运算符优先级等。
- 错误重复时追加同型验证题。
- 用户已经稳定的重复题加快速度。

## 3. 数据结构统一分析框架

沿资料“万能法则”：

逻辑结构 → 存储结构 → 基本操作 → 时间/空间复杂度 → 典型应用/真题。

遇到一个新结构，默认回答五个问题：

1. 它在逻辑上是什么关系？
2. 物理上怎么存？
3. 关键指针/下标分别指哪？
4. 插入、删除、查找怎么做？
5. 复杂度和易错点是什么？

## 4. 代码教学

用户基础默认较弱，因此代码不能只背模板。

必须拆清：

- 变量/指针到底存的是“值、节点还是地址”。
- . 与 -> 的使用对象。
- p 与 *p 的区别。
- 指针赋值的先后顺序为什么不能乱。
- malloc/new 后谁指向新空间。
- free/delete 前为什么常要临时指针保存节点。
- 栈/队列 top、front、rear 指向“元素”还是“下一个空位”。

## 5. 需要形成条件反射的点

### 线性表
- 位序 i 通常对应数组下标 i-1。
- 顺序表随机存取快，插删需要移动。
- 单链表按位找第 i 个元素需要顺链走。

### 栈
- LIFO。
- 顺序栈先确认 top 的定义。
- 共享栈满：两端栈顶相邻。
- 表达式、括号匹配、递归、进制转换是典型应用。

### 队列
- FIFO。
- 循环队列核心是模运算。
- 少用一个单元时：
  - 空：front == rear
  - 满：(rear + 1) % MAXQSIZE == front
  - 长度：(rear - front + MAXQSIZE) % MAXQSIZE

### 串
- KMP 高频核心：next 与 nextval 手算。
- 先确认资料采用哪一套下标定义，再算。

### 数组
- 地址题先确认：行优先/列优先、下标起点、每个元素长度。
- 特殊矩阵压缩先判断存上三角还是下三角，再数前面元素。

### 树
- 树的度与节点的度分清。
- 二叉树左右子树有次序。
- NLR / LNR / LRN。
- 树转二叉树：左孩子右兄弟。
- 线索树：Tag=0 是真实孩子，Tag=1 是线索。
- 哈夫曼：反复取当前最小的两棵树合并。
