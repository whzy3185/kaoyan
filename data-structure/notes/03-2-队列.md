# 03.2 队列

## 1. 定义

队列是先进先出 FIFO 的线性表。

- 队头：出队的一端。
- 队尾：入队的一端。

资料主要采用：rear 指向队尾元素的下一个位置。

## 2. 顺序队列与假溢出

普通顺序队列不断入队、出队后，front 会向后移动。

即使数组前部已经空出来，只要 rear 到达数组末尾，仍可能无法继续入队。

资料称这种“数组中有空位置但无法入队”为假溢出。

## 3. 循环队列

把数组逻辑上首尾相接。

实现关键：模运算。

指针前进一步：

(index + 1) % MAXQSIZE

资料用钟表说明模运算，例如 18%12=6。

## 4. rear 两种常见定义

资料专门比较：

1. front 指向队头，rear 指向队尾元素。
2. front 指向队头，rear 指向队尾元素的下一个位置。

后续任何公式必须先确认采用哪一种。

当前主资料大部分循环队列公式采用第 2 种。

## 5. 空与满冲突

如果只用 front 和 rear，并且采用 rear 指向下一空位：

- 队空可能是 front == rear。
- 如果把全部数组单元都用满，队满也可能出现 front == rear。

所以需要区分。

### 方案一：牺牲一个单元

队空：

front == rear

队满：

(rear + 1) % MAXQSIZE == front

队列长度：

(rear - front + MAXQSIZE) % MAXQSIZE

### 方案二：tag

资料定义：

- 删除成功后 tag=0。
- 插入成功后 tag=1。

当 front==rear：

- tag=0：空。
- tag=1：满。

### 方案三：num

额外记录队列中元素个数。

- num=0：空。
- num=MAXQSIZE：满。

## 6. 链队列

典型结构：

- Q.front：队头指针。
- Q.rear：队尾指针。
- 节点有 data + next。
- 通常带头结点。

资料强调 QNode 是结构体类型，QueuePtr 是指向该结构体的指针类型。

入队：

- 动态申请新节点。
- 接到 rear 后。
- rear 更新到新节点。
- 通常不需要像顺序队列那样判断固定数组是否满。

出队：

- 从 front 后的首元节点删除。
- 若删掉的是最后一个数据节点，需要同步修正 rear。

## 7. 高频易错

- rear 到底指哪。
- 空/满公式属于哪种约定。
- 模运算漏加 MAXQSIZE 导致负数。
- 链队列删除最后元素后忘记更新 rear。
