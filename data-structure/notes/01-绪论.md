# 01 绪论

## 1. 数据结构先看“关系”

资料把逻辑结构分成四类：

- 集合结构：元素之间不强调关系。
- 线性结构：一对一。
- 树结构：一对多。
- 图结构：多对多。

关键理解：逻辑结构只描述数据元素之间的关系，不关心物理上怎么存。

## 2. 四种存储结构

### 顺序存储

把数据按照逻辑顺序放在一片连续空间中。

优点：位置关系直接、随机访问方便。

资料重点强调缺点：在中间插入/删除时，需要移动后面大量元素，数据量大时开销明显。

### 链式存储

数据在物理空间可以离散，通过“链条/指针”连接。

核心好处：插入时主要改前后链接关系，不需要整体搬移后续数据。

节点最基本的抽象：

- data：数据域。
- next：指针域。

### 索引存储

建立附加的索引表，用关键字定位主数据表记录。

### 散列存储

通过关键字经过散列函数直接计算地址。

资料示例采用“地址 = 数据 % 30”，并明确说明冲突处理在后续内容再讲。

## 3. 时间复杂度

资料定义：算法中“基本语句”的执行次数随 n 的增长数量级。

大 O：

T(n)=O(f(n))

加法原则：

T(n)=O(max(f(n),g(n)))

乘法原则：

T(n)=O(f(n)g(n))

典型识别：

- 单循环到 n：O(n)。
- 双重各到 n：O(n²)。
- x 每次翻倍直到达到 n 量级：O(log₂n)。

资料 2011 例：

x=2；while(x<n/2) x=2*x；

结论：O(log₂n)。

## 4. 空间复杂度

资料按与时间复杂度相同的数量级思想分析额外空间。

重点是“峰值同时占用空间”，不能只机械数 malloc 出现次数。

## 5. 后续统一判断链

看到一个数据结构时先问：

逻辑关系是什么 → 用哪种存储结构实现 → 基本操作如何改变结构 → 时间/空间复杂度怎样。
