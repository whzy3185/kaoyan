# 02.1 顺序表

## 1. 线性表

资料中的线性表特征：

1. 是逻辑结构。
2. 元素个数有限。
3. 数据元素类型相同。
4. 除第一个元素外，每个元素只有一个直接前驱。
5. 除最后一个元素外，每个元素只有一个直接后继。

资料给出的学习顺序：

了解逻辑结构 → 分析存储结构 → 学习基本操作。

## 2. 顺序表的定位

线性表是逻辑结构。

顺序表是线性表的顺序存储实现。

两者不要混成同一个概念。

## 3. 连续存储与地址

若第一个元素地址为 b，每个元素占 s 个存储单元，则位序 i 的元素地址为：

b+(i-1)s

注意资料明确区分：

- 位序：1,2,3,...
- C 数组下标：A[0],A[1],A[2],...

因此“第 i 个元素”常对应数组下标 i-1。

## 4. 典型结构

资料使用 SqList 结构体保存：

- elem：顺序存储空间基地址。
- length：当前长度。

初始化的核心过程：

1. 为 elem 申请一段数组空间。
2. 申请失败则退出。
3. length=0。
4. 返回成功状态。

## 5. 基本操作的理解

### 取值

已知位序可直接由连续地址计算位置，所以顺序表具有随机存取特点。

### 按值查找

从头比较，直到命中或扫描结束。

### 插入

核心：

1. 判断位置与容量是否合法。
2. 从后往前移动插入位置及其后的元素。
3. 把新元素放入目标位置。
4. 长度加 1。

### 删除

核心：

1. 判断删除位置合法。
2. 保存被删元素（如果接口需要返回）。
3. 从删除位置后一个元素开始向前移动。
4. 长度减 1。

## 6. 考试容易错

- “位序 i”与“下标 i”差 1。
- 顺序表的优势来自连续存储。
- 中间插入/删除的主要成本来自元素移动。
- 代码里 SqList L 是结构体变量时，用“.”访问成员。
