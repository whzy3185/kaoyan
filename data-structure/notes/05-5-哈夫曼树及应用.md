# 05.5 哈夫曼树及其应用

## 1. 基本概念

### 路径

树中一个节点到另一个节点之间经过的分支。

### 路径长度

路径上的分支数。

### 节点的带权路径长度

节点权值 × 从根到该节点的路径长度。

### 树的带权路径长度 WPL

所有叶子节点带权路径长度之和。

WPL = Σ w_k l_k

资料给出的另一种计算法：

WPL = 所有非叶节点权值之和

这个结论在按哈夫曼构造得到的树上计算非常方便。

## 2. 哈夫曼树定义

在给定叶子权值条件下，WPL 最小的二叉树。

## 3. 构造算法

给定 n 个权值：

1. 每个权值先成为一棵单节点树，形成森林 F。
2. 从 F 中选根权值最小的两棵树。
3. 把它们作为左右子树，建立新根，新根权值=两者之和。
4. 从 F 删除原两棵，加入新树。
5. 重复，直到只剩一棵树。

核心条件反射：

每轮只看“当前森林”中最小的两个根权值。

不能提前固定配对。

## 4. 资料示例

初始权值：

1,2,5,6,7

逐步合并后形成根权值 21。

练习权值：

10,12,16,21,30

正确构造过程的合并权值包括：

22、37、52、89

资料同时展示了错误典例，目的在提醒：每轮必须重新选当前最小两项。

## 5. 哈夫曼树性质

资料列出：

1. WPL 最小。
2. n 个初始叶子，构造过程中新增 n-1 个内部节点，总节点数 2n-1。
3. 哈夫曼树只有度 0 和度 2 的节点，不存在度 1 节点。
4. 权值越小的节点通常离根越远。

## 6. 哈夫曼编码

应用思想：

出现频率高的字符应该拥有更短编码。

资料先用普通编码和变长编码比较长度，再引出哈夫曼编码。

### 前缀编码

任何一个编码都不能是另一个编码的前缀。

例如：

A=0，B=01

不满足，因为 0 是 01 的前缀。

A=0，B=10

满足。

哈夫曼编码：

- 一定是前缀编码。
- 是最优前缀编码。

## 7. 资料编码例

字符频数：

A=10，B=12，C=30，D=16，E=21

由相同权值构造哈夫曼树后，资料给出一套编码：

- A：000
- B：001
- C：01
- D：10
- E：11

左右边取 0/1 的具体分配可以互换，因此具体码字可能不同，但码长与最优性结构保持对应。

## 8. 资料内部不一致

某页题面写“AAABBC”，后续编码串按“AAABBCC”展示。

后续若使用这个例子，先明确采用哪一个字符序列，不能把两者混着算。
