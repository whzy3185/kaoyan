# 04.2 数组

## 1. 定义与存储

数组由类型相同的数据元素构成，是有序集合。

资料强调数组使用顺序存储。

一维数组：

LOC(a_i)=LOC(a_0)+iL

其中 L 是每个元素占用的存储长度。

## 2. 二维数组

设行下标 [0,h1]，列下标 [0,h2]。

### 行优先

LOC(a_i,j)=LOC(a_0,0)+[i(h2+1)+j]L

理解：先放完第 0 行，再第 1 行。

### 列优先

LOC(a_i,j)=LOC(a_0,0)+[j(h1+1)+i]L

理解：先放完第 0 列，再第 1 列。

## 3. 特殊矩阵压缩

资料列出：

- 对称矩阵。
- 三角矩阵。
- 对角/三对角带状矩阵。

核心思想：利用矩阵分布规律，只保存必要元素。

## 4. 对称矩阵

满足：

a_ij=a_ji

只需保存上三角或下三角（含主对角线）。

资料重点不是死背某一条公式，而是“三步数前面有多少元素”：

1. 判断 a_ij 在存储三角内还是另一侧。
2. 若在另一侧，先用对称性换成 a_ji。
3. 数出它前面已经存了多少元素，该数量就是一维数组下标（当数组从 A[0] 起）。

### 资料例：5×5 下三角按行优先

- a_3,5 属于上三角 → 转为 a_5,3 → A[12]。
- 若矩阵从 a_0,0 记，a_3,2 的例子得到 A[8]。

### 同一矩阵按列优先保存下三角

资料例：

- a_3,5 → a_5,3 → A[11]。
- a_3,2 → A[10]。

结论：行优先/列优先会改变压缩下标。

## 5. 三角矩阵

三角区域外全部是 0 或同一常数 c。

存储：

- 三角区域元素。
- 再留一个位置存常数 c。

资料例：按行优先存下三角，A[26] 是第 27 个被存元素。

由：

1+2+...+n ≥ 27

定位到第 7 行，再减去前 6 行 21 个元素，得到第 7 行第 6 列。

## 6. 三对角矩阵

非零元素集中在主对角线及其上下各一条平行线。

资料例假设矩阵第一项 a_0,0：

求 a_20,21。

- 第 1 行有 2 个。
- 中间各行有 3 个。
- 前 20 行共 2+19×3=59 个。
- a_20,21 是第 21 行第 3 个，即总第 62 个。
- 数组 A[0] 存第 1 个，所以位置 A[61]。

## 7. 资料真题

### 2020

10×10 对称矩阵，上三角按列优先存入 C 一维数组 N，求 m_7,2 下标。

先对称为 m_2,7。

前 6 列共 1+2+...+6=21 个，第 7 列走到第 2 个，总第 23 个，因此下标 22。

答案：C。

### 2021

二维数组行优先，每元素 1 单元。

A[0][0] 地址 100，A[3][3] 地址 220。

从首元素到 A[3][3] 共 121 个元素：

3n+4=121 → n=39

A[5][5] 是从 0 下标计算的第 201 个元素，地址 300。

答案：B。

## 8. 做题固定检查

行优先还是列优先 → 存上三角还是下三角 → 矩阵下标从 0 还是 1 → 数组下标从 0 还是 1。
