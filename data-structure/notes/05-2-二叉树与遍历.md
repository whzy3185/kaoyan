# 05.2 二叉树与遍历

## 1. 二叉树基本性质

资料给出：

1. 第 i 层最多 2^(i-1) 个节点。
2. 深度 k 最多 2^k-1 个节点。
3. 任何二叉树：
   n0 = n2 + 1

其中：

- n0：叶子节点数。
- n2：度为 2 的节点数。

推导依据：

节点总数 = 度数和 + 1

n0+n1+n2 = n1+2n2

所以 n0=n2+1。

## 2. 满二叉树与完全二叉树

### 满二叉树

深度 k 且节点数达到最大：

2^k-1

### 完全二叉树

可理解为：

与同深度满二叉树的 1..n 编号位置一一对应。

资料直观表述：从满二叉树最下层的最右边开始连续删除节点得到。

## 3. 完全二叉树性质

- 叶子只可能出现在最下面两层。
- 具有 n 个节点时深度：
  floor(log2 n)+1
- 按层序从 1 编号：
  - i=1 是根。
  - i>1 时双亲：floor(i/2)。
  - 若 2i≤n，左孩子：2i。
  - 若 2i+1≤n，右孩子：2i+1。

这些结论需要形成条件反射。

## 4. 存储结构

### 顺序存储

资料重点用于完全二叉树。

一般稀疏/单支二叉树会浪费大量数组位置。

### 链式存储

二叉链表最少：

- data
- lchild
- rchild

三叉链表再加：

- parent

## 5. 遍历

### 先序 NLR

根 → 左 → 右。

### 中序 LNR

左 → 根 → 右。

### 后序 LRN

左 → 右 → 根。

资料示例树得到：

- 先序：A B D C E F
- 中序：B D A E C F
- 后序：D B E F C A

## 6. 层序遍历

按层从上到下、每层从左到右。

实现核心：辅助队列。

流程：

1. 根入队。
2. 队列非空时出队一个节点并访问。
3. 它的左孩子存在则入队。
4. 右孩子存在则入队。
5. 重复。

资料示例层序：

A B C D E F

## 7. 由遍历序列重建二叉树

资料结论：

只给先序/中序/后序中的任一种，通常无法唯一确定二叉树。

关键是中序 + 另一种能定位根：

- 先序 + 中序：先序第一个是根。
- 后序 + 中序：后序最后一个是根。

在中序中找到根，就能切分左右子树，再递归处理。

资料还用 2011 真题讨论“先序和后序已知时，中序哪一个不可能”，说明只靠先序+后序通常仍不唯一，需要逐个候选验证。
