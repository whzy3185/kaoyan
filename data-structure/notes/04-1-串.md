# 04.1 串

## 1. 定义

串：零个或多个字符组成的有限序列。

资料记法：

s="a1a2...an"

- s：串名。
- a_i：字符。
- n：串长。

## 2. 模式匹配

资料重点：

1. BF（Brute-Force）暴力匹配。
2. KMP。

### BF

失配后主串起点逐位后移，再从模式串头重新比较。

问题：已经得到的信息被重复浪费。

## 3. KMP 的直觉

资料用模式串 ABCAC 反复演示。

核心句：

失配时，寻找“失配位置之前已经匹配部分”的最长相等前后缀。

例如已匹配 ABCA：

- 前缀：A、AB、ABC。
- 后缀：A、CA、BCA。
- 最长相等前后缀是 A。

于是模式串不必整体只右移一格，可以把“前缀 A”对齐到原来的“后缀 A”。

注意：真实内存中字符串本身不移动，实际是比较指针改变。

## 4. next 数组

资料定义思想：

当模式串某位置失配时，next 告诉我们模式串中的哪一位置重新与当前主串字符比较。

对于模式串 ABCAC，资料给出一套位序 1..5 的 next：

0 1 1 1 2

随后又给出“整体减 1”的 -1 起始风格：

-1 0 0 0 1

这两套是不同下标约定下的等价表示思路。

### 必须先确认约定

资料同时出现：

- 模式串位序从 1 开始，next 值按 0/1 风格表达。
- C 数组下标从 0 开始，next 可从 -1 开始。

因此后续做题第一步必须问：

题目给的是哪一套 next 定义？

不能把不同教材公式直接混用。

## 5. nextval

next 的进一步优化。

资料动机：

如果失配跳转后，新比较字符与刚才失配字符相同，那么这次比较必然还会失败，是无效比较。

nextval 用来继续跳过这种重复。

资料给出的求法：

逐位观察 next。

- 比较“本位字符”与“本位 next 值所对应的字符”。
- 若相同：nextval 继续取那个位置的 next 值。
- 若不同：nextval 就沿用本位 next 值。

对 ABCAC，资料演示得到：

next：0 1 1 1 2

nextval：0 1 1 0 2

## 6. 考试重点

资料最后明确强调：

KMP 真正核心、高频易考点就是手算 next 与 nextval。

因此后续学习这一节必须安排连续手算训练，直到下标规则稳定。
