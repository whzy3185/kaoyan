## 单题运行字段

长期刷题时至少维护：

- `id`
- `year`
- `question_no`
- `type`
- `topic/subtopic`
- `source_url/source_page`
- `user_answer`
- `result`
- `error_tags`
- `review_status`
- `last_reviewed_at`

## 刷题原则

- 题面必须完整，不把题拆到只剩最后一步机械运算。
- 第一次做题先不给答案。
- 图、拓扑、报文首部、路由表、TCP时序题必须读取完整原题。
- 用户作答后精确指出错误位置，再讲原因。
- 真题与讲义练习分开统计。
- 错题进入复测；同类错误重复时追加验证题。
