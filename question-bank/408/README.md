# 408 计算机网络真题库（2009—2023）

本目录只维护计算机网络真题。

当前已定位 **135 题**：

- 2009—2023 共 15 年。
- 每年 8 道网络选择题。
- 每年 1 道网络综合应用题。
- 合计 120 道选择题 + 15 道综合题 = **135 题**。

## 文件

- `INDEX.md`：按年份列出全部题号和知识点。
- `BY_TOPIC.md`：按知识点重新聚合全部真题。
- `questions.jsonl`：机器可读索引。
- `刷题进度.md`：首刷、错题与复测记录。

## 使用规则

1. 真题索引只保存年份、题号、知识点和原题定位，不提前把答案放在刷题页面。
2. 真正做题时，根据年份和题号读取完整题干、选项、拓扑图、表格或报文内容。
3. 图形题、时序题、首部字段题不能仅靠摘要作答。
4. 做完后更新错题标签与复测状态。
5. 该题库与本分支的 BOK25 基础课资料联动：不会的题回到对应章节补知识。

## 来源说明

`408真题` 分支已经确定 2009—2023 的 408 真题工作流，但当前其中实际落盘的是数据结构子库。这里已单独整理出计算机网络部分；题号与知识点定位依据同一批 408 年卷的公开结构化索引，完整题面按需回原卷/来源页核对。
