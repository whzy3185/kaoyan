# 2009—2023 408 计算机网络真题题库

本目录只维护 **计算机网络**。不复制数据结构、计组或操作系统题目。

当前已从 2009—2023 年 408 真题中定位 **135 道计算机网络题**：每年 8 道选择题 + 1 道综合题，共 15 年。

## 组织方式

- `INDEX.md`：全部 135 题总索引。
- `01-概述与体系结构.md` ～ `06-应用层.md`：按本项目六章知识体系排列。
- `07-跨层综合.md`：同时覆盖多个层次的综合应用题。
- `questions.jsonl`：机器可读元数据；包含年份、题号、知识点、来源与答案键。
- `刷题进度.md`：按年份记录首刷、错题和复测状态。

## 题面策略

知识点文件保存“年份-题号 + 知识点摘要 + 来源定位”，默认不预先展示答案。真正刷某题时，再根据 `source_url` / 原始 408 卷读取完整题面、选项、图、表和代码，避免转写丢失图示信息。

## 来源

- 本仓库 `408真题` 分支用于确定本项目的 2009—2023 真题范围与刷题工作流。
- 由于该分支当前只实际归档了“数据结构”子库，计算机网络题目定位由公开结构化 408 题库 `JayLeo04/schedule` 中对应年份的 `questions.json` 补齐。
- 以后若原始 408 PDF 在本项目中重新可用，以原 PDF 为最终题面依据。
