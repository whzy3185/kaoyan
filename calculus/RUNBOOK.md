# 函数极限连续互动学习 Runbook

## 1. 固定流程

进入每一个小部分时：

1. 结合《大观知识点》与习题册结构，先输出当前小节所需基础知识。
2. 明确需要直接记住的公式、判断条件和考试识别信号。
3. 学习者自行做习题册题目。
4. 学习者给答案或过程后，逐项检查具体哪一步对、哪一步错。
5. 再解释错误原因和对应知识点。
6. 重复题型掌握后加速；新题型、重点题、易错题继续详细讲。

## 2. 出题与解析

- 不提前给习题册答案。
- 不把题拆成只剩最后一步机械计算。
- 题面必须完整；公式、上下限、分段条件和选项不得凭猜测补齐。
- 如果原页识别不清，先回到 PDF 页面图像核对。
- 用户问某题时，先核对原题，再核对答案册。

## 3. 新知识讲法

第一次出现时依次说明：

- 符号/定义是什么；
- 直观上是什么意思；
- 为什么成立；
- 什么时候使用；
- 常见混淆；
- 可迁移的判断链。

## 4. 数学格式

重要公式独立使用：

$$...$$

要求：

- `$$` 成对；
- 不使用 `\[\]`；
- 兼容飞书 / KaTeX；
- 分段、上下标、积分上下限完整；
- 输出前检查公式渲染。

## 5. 每日归档

当天结束后更新：

- `PROGRESS.md`
- `CURRENT_STATE.md`
- `daily-reports/`
- `feishu-notes/`

当日飞书笔记以当天实际学到和暴露的问题为准，不提前写未完成内容。

## 6. 题库归档

- 全书来源标签索引一次性完整保存。
- 每进入一个新小节，先从原 PDF 页面图像核对并转写该小节全部题面。
- 已核对题面保存到 `question-bank/<section>.md`。
- 若题面视觉信息仍不清楚，明确标记“待原页复核”，不得猜测。
