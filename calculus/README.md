## 学习流程

每进入一个小部分：

1. 先结合《大观知识点》整理该小节必需的基础知识、公式、判断链和易错点。
2. 学习者自己做题，不提前给答案。
3. 学习者提出题目或答案后，逐步核对、指出具体错误并解析。
4. 同类错误重复出现时追加同型验证题，连续稳定后通过。
5. 当天结束后更新飞书笔记、日报、进度和续学断点。
6. 每进入一个新小节，先把该小节题面从原 PDF 图像中核对、转写并归档到 `question-bank/`；不得凭识别不清的内容猜题。
