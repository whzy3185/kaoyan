# 学习资料来源

## 主资料

1. `1.函数极限连续.pdf`
   - 习题册。
   - PDF 共 169 页。
   - PDF 第 1–6 页为封面、目录等前置内容。
   - PDF 第 7–169 页为题库正文，共 163 页。
   - 当前按可检索的“来源标签条目”统计到 876 个题目条目。
   - 题面中大量公式与选项嵌在图片中，因此不能只依赖 PDF 文本层；每进入一个小节时需要回看原页图像核对完整题面。

2. `极限答案册.pdf`
   - 配套答案册。
   - PDF 共 634 页。
   - 用于核对答案、解析、公式、特殊条件和题型分类。

3. `【高数合集】大观知识点.pdf`
   - 知识点主参考。
   - PDF 共 66 页。
   - 用于每个小节开始前整理定义、结论、判断链、常见误区和考试识别信号。

4. `1.函数极限连续(1).pdf`
   - 与答案册内容一致的重复文件，作为备用核对来源。

## 来源使用规则

- 讲解顺序以习题册原有章节、题型和顺序为主。
- 每进入一个小部分，先查《大观知识点》对应内容，再进入做题。
- 做题时先由学习者独立完成；答案册只用于核对，不能提前泄露答案。
- 原题公式、分段、积分上下限、选项或条件识别不清时，必须回看原 PDF 页面图像，不自行猜测。
- 题库索引与题面归档分开：
  - `source-index-*.txt` 保存全书 163 页、876 个来源标签条目的完整索引；
  - 各小节 `.md` 保存经过页面图像核对后的完整题面。
