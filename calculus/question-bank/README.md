## 为什么同时保存“索引”和“小节完整题面”

本 PDF 的题目正文大量以图片形式嵌入，PDF 文本层通常只能稳定抽取：

- 章节名；
- 题型名；
- 年份 / 数一二三；
- 880 / 900 / 1000 / 660 等来源标签；
- 题号。

公式、选项、图表和积分上下限常不在文本层中。

因此本仓库采用两级归档：

1. **全书索引**：一次性覆盖全部 163 页和 876 个来源标签条目。
2. **小节完整题面**：进入该小节前，直接查看原 PDF 页面图像，逐题核对并转写，避免批量 OCR 把公式识别错。
