## 视频 1：时间复杂度

### 已掌握的判断链

1. 单层线性循环：基本语句执行次数与 n 同阶时写 O(n)。
2. 倍增/倍乘循环：i *= c 时，先写 1,c,c²,...，循环轮数通常是 O(log n)。
3. 累加型循环：sum += i 时先写 1+2+...+t，再用退出条件求 t；典型得到 O(√n)。
4. 递归：参数 n→n-1 时先看递归深度；参数每次减半时深度为 O(log n)。
5. 普通 n×n 嵌套：内层每轮固定执行 n 次时为 O(n²)。
6. 外层倍增、内层跑到 i：总工作量是 1+c+c²+...，按几何级数求和，典型为 O(n)。
7. 外层线性、内层倍增：n 轮 × 每轮 log n，得到 O(n log n)。
8. 内层上界依赖 i：如每轮约 log i 次，总和可到 O(n log n)。
9. 外层、内层都倍增且互相制约：各轮为 log n, log n-1,...,1，总和为 O((log n)²)。
10. 变步长 j += i：总工作量 n+n/2+...+n/n = nH_n，得到 O(n log n)。
11. 空间复杂度：看“同时占用的额外空间”，循环次数本身不直接决定空间复杂度；递归空间由最大递归深度决定。

### 实际暴露的易错点

- 把“外层循环轮数是 log n”直接当成整个程序复杂度，忽略内层累计工作量。
- 对“外层倍增、内层跑到 i”先后误判为 O(log n)、O(n log n)；纠正后已能用几何级数得到 O(n)。
- 对“外层倍增、内层从 i 倍增到 n”曾误判 O(n log n)；纠正后能写出 log n + (log n-1) + ... + 1 = O((log n)²)。
- 对“第 i 轮内层约 log i 次”曾先答 O(n)；纠正后能理解多数后半轮已是 log n 级，合计 O(n log n)。

### 需要保留的做题动作

先写：

第几轮 → 变量值 → 本轮执行次数 → 退出条件 → 总和/主导项

复杂嵌套不要凭“有几层循环”直接判断。

## 视频 2：线性结构

### 1. 线性表与链表

已掌握：

- 顺序表按位访问 O(1)，链表按位访问 O(n)。
- 已知结点 p 地址，在 p 后插入/删除后继结点本身是 O(1)。
- 已知 p 地址但要正常删除 p 本身，单链表还需找前驱，整体可为 O(n)。
- 顺序表第 i 位插入移动 n-i+1 个元素；删除第 i 个元素移动 n-i 个元素。
- 链表操作先画“前驱—当前—后继”，先接好剩余链，再释放结点。

出现过的错误：

- 曾把“已知 p，在 p 后插入”误判为 O(n)。
- 曾把顺序表删除第一个元素误判为移动 0 个，已纠正为 n-1。

### 2. 栈、队列与 Catalan

已掌握：

- 栈后进先出，能用模拟判断合法出栈序列。
- 受限双端队列按允许方向逐步模拟。
- 队列保持相对顺序，栈负责局部逆序。
- Catalan 数：C_n = 1/(n+1) × C(2n,n)，并能计算基础组合数。

出现过的错误：

- “前 3 个入栈逆序、后两个直接输出”曾把后两个也反转；纠正后已能区分哪些元素经过栈。
- Catalan 计算中曾把最终结果 14 当成 C(8,4)，已纠正：C(8,4)=70，C_4=14。

### 3. 循环队列

已掌握三套判空/判满：

- 空一格法：空 rear==front；满 (rear+1)%MAXSIZE==front；长度 (MAXSIZE+rear-front)%MAXSIZE。
- num 法：空 num=0；满 num=MAXSIZE。
- tag 法：front==rear 时结合最近一次操作判断，课程约定 tag=0 表示删除后为空，tag=1 表示插入后为满。

当前这部分回答稳定。

### 4. 表达式与栈

已掌握：

- 后缀表达式从左向右：数字入栈；运算符弹两个数，注意减法/除法的左右顺序。
- 中缀转后缀：操作数直接输出；运算符比较优先级；左括号入栈；右括号弹到左括号。
- 对 +、-、*、/：新运算符优先级低于或等于栈顶时，先弹栈；更高时直接入栈。

出现过的错误：

- 曾把“栈顶 *，新来 +”判断为 + 直接入栈。
- 曾把“栈顶 +，新来 *”判断为先弹 +。
- 曾把同优先级 * 与 / 判断为直接入栈；已纠正为左结合下先弹栈。
- 中缀转后缀时曾改变操作数相对顺序；现已能正确写出 AB-C*D+ 等形式。

### 5. 特殊矩阵与二维数组

已掌握：

- n 阶对称矩阵压缩需要 n(n+1)/2 个元素。
- 下三角按行、数组从 0 开始：a_ij(i≥j) 的位置可由“前 i-1 行元素数 + 本行偏移”得到。
- 三对角矩阵共有 3n-2 个非零元素；按行压缩时先数前面各行已存元素。
- 二维数组行优先：A[i][j] 前有 i×列数+j 个元素；地址 = 首地址 + 偏移元素数×元素字节数。

出现过的错误：

- 对称矩阵 a_32 曾答下标 5，纠正为 4。
- 三对角矩阵 a_43 曾答 11，纠正为 8；随后 a_54 能正确答 11。
- 二维数组行优先开始时不熟悉，经过“先数完整行，再数本行前几个”后已稳定。

### 6. KMP

已掌握：

- 真前缀/真后缀不能包含整个字符串本身。
- 能求最长相同真前缀、真后缀。
- 课程约定下 next 前两项为 0、1；从后续位置看“当前位置之前的子串”。
- 能按课程下标体系计算 next，如 AABAB → 0,1,2,1,2。
- nextval：当前字符与 next 指向字符不同就保留 next；相同则沿 nextval 继续跳，避免重复比较。
- 实际匹配中主串指针 i 不回退，模式串指针 j 按 next/nextval 跳；字符相等和不等都计入比较次数。

出现过的错误：

- 曾把 ABABA 整串当成自己的真前后缀，已纠正。
- 求 AB 的相同真前后缀时曾答长度 1，已纠正为 0。
- next 数组早期出现过项数和数值混淆，连续练习后 AABAB 已独立正确。
- nextval 目前能解释 ABABA 中第 4 位为什么最终跳到 1：先遇 B=B 继续跳，再到 B≠A 停止。
