## 使用原则

1. 教学先读 knowledge，再做 questions，用户作答后才查 answers。
2. GitHub 中保存按页解析文本与页码映射。
3. 对公式、图形、手写推导存在编码歧义的页面，以原 PDF 页面图像为准，不根据损坏字符猜题。
4. 每个子模块 README 记录原始文件名、页数、SHA-256 和主题结构。
