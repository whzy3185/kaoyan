## 来源版本

当前提供三种排版版本：

- A4 紧凑版：150 页。
- A4 留白版：303 页。
- 横版：770 页。

三者均为“数一大观严选题做题本”的排版版本。仓库以横版作为题面归档基准，因为横版前 3 页为封面/序言，随后每页恰好对应 1 道严选题，便于建立稳定的 1–767 题号映射。

## 归档原则

1. 保留原题顺序和原资料分类。
2. 不提前写答案。
3. 数学公式优先保留 PDF 解析文本；发现字体编码导致的符号歧义时，回到原 PDF 页面图像核对。
4. 学习时按“进入小节 → 基础知识 → 用户独立做题 → 核对答案 → 错题记录”的流程推进。
