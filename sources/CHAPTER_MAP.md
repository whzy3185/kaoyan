# 计算机网络章节知识地图

更新时间：2026-09-20

本文件依据当前已上传的 BOK25 计算机网络资料整理，作为后续教学、真题分类与覆盖率统计的主索引。

## 第1章 计算机网络概述

### 主干
- 互联网与互连网
- 计算机网络组成
- 电路交换、报文交换、分组交换
- 网络分类
- 性能指标
- OSI、TCP/IP、五层体系结构

### 真题识别信号
- 发送时延、传播时延、处理时延、排队时延
- 吞吐量、带宽、时延带宽积
- 分组交换端到端总时延
- 各层功能与PDU

## 第2章 物理层

### 主干
- 数据通信系统模型
- 模拟/数字信号、码元、波特率、比特率
- 奈奎斯特准则与香农公式
- 编码与调制
- 信道复用
- 传输媒体
- 中继器、集线器

### 真题识别信号
- “无噪声/理想信道” → 奈奎斯特
- “带宽 + 信噪比” → 香农
- 码元状态数与比特率换算
- FDM/TDM/WDM/CDM

## 第3章 数据链路层

### 主干
- 封装成帧、透明传输、差错检测
- CRC
- 停止等待、连续ARQ
- GBN/SR与窗口
- 信道利用率
- ALOHA、CSMA、CSMA/CD、CSMA/CA
- LAN/WAN与以太网
- MAC帧
- 交换机自学习
- PPP
- VLAN与802.1Q

### 真题识别信号
- 生成多项式/余数 → CRC
- RTT、帧长、链路速率 → 信道利用率
- 序号位数、窗口大小 → GBN/SR
- 最短帧长 → CSMA/CD
- MAC表变化 → 交换机自学习
- 冲突域/广播域计数
- VLAN Tag 4B

## 第4章 网络层

### 主干
- 数据报服务与网络层两个层面
- IPv4地址、分类地址、CIDR
- IP数据报
- IP地址与MAC地址
- ARP
- IP分组转发
- 最长前缀匹配
- ICMP
- IPv6
- RIP、OSPF、BGP
- IP多播与IGMP
- NAT/NAPT
- 移动IP
- 路由器与SDN

### 真题识别信号
- IP + 掩码 → 网络号/广播地址/可分配主机范围
- 子网需求 → 借位与CIDR
- 路由表多条匹配 → 最长前缀
- TTL归零/不可达 → ICMP
- 距离向量 → RIP
- 链路状态 → OSPF
- AS之间 → BGP
- 私网地址转换 → NAT/NAPT
- IP与MAC在逐跳转发中的变化

## 第5章 传输层

### 主干
- 进程到进程通信
- 端口、复用和分用
- UDP
- TCP连接
- TCP首部
- TCP可靠传输
- 流量控制
- 拥塞控制
- 连接建立和释放

### 真题识别信号
- TCP“面向字节流”
- 序号 = 本报文段第一个数据字节编号
- 确认号 = 期望收到的下一个字节
- rwnd → 流量控制
- cwnd/ssthresh → 拥塞控制
- 三次握手/四次挥手状态变化
- 超时重传、快重传、快恢复
- UDP 8B首部

## 第6章 应用层

### 主干
- C/S与P2P
- DNS
- DHCP
- FTP
- SMTP、MIME、POP3
- WWW、URL、HTTP

### 高频端口/运输层关系
- DNS：通常53
- DHCP：服务器67 / 客户68，基于UDP
- FTP：控制21 / 数据20（资料按主动模式讲解）
- SMTP：基于TCP
- POP3：基于TCP
- HTTP：基于TCP（按当前资料体系）

按资料原顺序推进：
第1章 → 第2章 → 第3章 → 第4章 → 第5章 → 第6章。

如果用户选择“直接刷真题”，则以真题为入口，遇到薄弱知识点时回到对应PDF进行局部补课。
