## 阶段性错因汇总：视频 1～2（2026-09-28）

> 这些来自课堂例题/变式训练，不冒充目标院校或 408 独立真题记录。后续真题仍按上面的正式模板逐题追加。

### 1. 复杂嵌套循环：把“外层轮数”当成“总复杂度”

- 来源：视频 1《时间复杂度》
- 错误类型：复杂度 / 算法流程
- 典型错误：
  - 外层 i*=c、内层跑到 i 时，曾答 O(log n) 或 O(n log n)。
  - 外层 i*=2、内层从 j=i 倍增到 n 时，曾答 O(n log n)。
- 正确判断链：
  - 先列每一轮内层工作量。
  - 1+c+c²+... 用几何级数求和，典型为 O(n)。
  - log n, log n-1,...,1 求和，典型为 O((log n)²)。
- 下次信号：看到“内层边界依赖外层变量”时，先逐轮列次数，禁止直接按循环层数相乘。

### 2. 单链表：已知结点地址后仍把局部插入判为 O(n)

- 来源：视频 2《线性结构》
- 错误类型：概念 / 指针
- 典型错误：已知 p 地址，在 p 后插入新结点时曾答 O(n)。
- 正确判断链：
  - 已知 p 后，s->next=p->next；p->next=s，是固定次数操作。
  - 只有“还需要先找到 p/前驱”时，整体才可能 O(n)。
- 下次信号：题干出现“已知 p 的地址”，先把查找成本从局部指针操作里剥离。

### 3. 顺序表删除：移动元素个数判断错误

- 来源：视频 2《线性结构》
- 错误类型：下标 / 计算
- 典型错误：删除第一个元素曾答移动 0 个。
- 正确判断链：
  - 删除第 i 个：后面第 i+1 到第 n 个前移，共 n-i 个。
  - 删除第一个：n-1 个。
  - 第 i 位插入：原第 i 到第 n 个后移，共 n-i+1 个。

### 4. 队列 + 栈：把未经过栈的元素也逆序

- 来源：视频 2《线性结构》
- 错误类型：算法流程
- 典型错误：前 3 个进栈逆序、后 2 个直接输出时，把后 2 个也反转。
- 正确判断链：
  - 栈只反转进入栈的局部段。
  - 直接输出/队列路径保持原相对顺序。

### 5. 中缀转后缀：运算符优先级弹栈方向混淆

- 来源：视频 2《线性结构》
- 错误类型：算法流程
- 典型错误：
  - 栈顶 *、新来 + 时曾判断 + 直接入栈。
  - 栈顶 +、新来 * 时曾判断先弹 +。
  - 栈顶 *、新来 / 时曾忽略同级左结合。
- 正确判断链：
  - 新运算符优先级更高：直接入栈。
  - 新运算符优先级更低：先弹栈。
  - + - * / 同级：左结合，先弹栈。
  - 左括号直接入栈；右括号弹到左括号。

### 6. 压缩矩阵：0 起始下标与“前面已存多少”混淆

- 来源：视频 2《线性结构》
- 错误类型：下标 / 计算
- 典型错误：
  - 对称矩阵 a_32 曾答下标 5，正确为 4。
  - 三对角矩阵 a_43 曾答 11，正确为 8。
- 正确判断链：
  - 先数当前位置之前已经存了多少元素。
  - 再根据题目明确数组下标从 0 还是 1 开始。
- 下次信号：先列一小段“元素 → 一维下标”验证公式。

### 7. KMP：真前后缀边界

- 来源：视频 2《线性结构》
- 错误类型：概念
- 典型错误：
  - 曾把 ABABA 整串当作自己的真前后缀。
  - AB 的最长相同真前后缀曾答长度 1，正确为 0。
- 正确判断链：
  - 真前缀/真后缀不能等于整个子串。
  - 必须“内容相同”才计入长度。

### 8. KMP：next/nextval 早期下标体系混淆

- 来源：视频 2《线性结构》
- 错误类型：下标 / 算法流程
- 当前状态：
  - 已能独立写出 AABAB 的 next：0,1,2,1,2。
  - 已理解 ABABA 的 nextval：0,1,0,1,0。
  - 已理解失配时 i 不回退，j 按 next/nextval 连续跳。
- 后续复做：
  - 换成教材 -1 起始版本时，必须先确认题目定义再换算。
  - 继续练完整匹配与字符比较次数。
