## 总原则

1. 只服务考研数学一概率统计范围。
2. 先完整学完知识体系，再统一刷题库，不在知识阶段机械追求题库覆盖率。
3. 真题阶段优先覆盖 2010 年及以后数一真题，以及数一 / 数三共同真题；不为补年份刻意刷更早真题。
4. 学习节奏默认“讲一点 → 做一题 → 检查 → 继续”。
5. 新知识先讲公式、意义和使用条件，再给完整题目；学过的公式在练习中不预填，让学习者自己写。
6. 不把题拆到只剩最后一步机械计算；需要时由学习者完成关键列式和判断，纯硬算可以直接给完整过程。
7. 同类错误重复出现时，追加同型验证题，连续答对后再通过。
8. 每日结束输出一次“今日学习目标已完成”，并给出可直接粘贴飞书的当日笔记。
