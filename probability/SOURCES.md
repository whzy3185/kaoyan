# 学习资料来源

1. `【无间隙】概率统计题库.pdf`
   - 本项目的主题库。
   - 题目总数：317 题。
   - 用途：知识阶段用于选取典型题 / 真题验证；知识体系完成后用于系统刷题与覆盖率审计。

2. `【A4版】概率统计 答案册.pdf`
   - 与主题库配套的答案与解析来源。
   - 用途：核对题目答案、解析、公式与计算过程。

3. `【框图版】概统知识点.pdf`
   - 主知识框架资料。
   - 用途：建立知识树、章节关系、抽样分布 / 六大统计量 / 参数估计 / 区间估计与假设检验的结构化框架。

4. `【文本版】概统知识点.pdf`
   - 主知识点文本版。
   - 用途：核对概念、章节顺序与考纲范围。

5. `27张宇基础30讲概率.pdf`
   - 辅助资料。
   - 用途：仅在主线需要补充解释、例题或直觉时参考，不按其例题顺序盲目推进。

## 来源使用规则

- 讲解优先级：主 PDF / 框图版 / 文本版 > 题库与答案册 > 张宇资料补充。
- 若主 PDF 对应知识点存在示意图、例题图或结构图，讲解时优先使用原资料图片，不自行生成替代图。
- 对题目、答案或年份存在冲突时，以实际题库 / 答案册原页核对结果为准。
- 知识阶段不追求题库完成率；完整学完知识体系后再统一进行题库覆盖率审计。
- 最终题库覆盖目标：≥95%。
- 真题优先：2010 年及以后数一真题，以及数一 / 数三共同真题。
